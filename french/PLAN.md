## 3. 난이도 설계 (A2~C1 섞기)

### 언어 장치

- **인턴 레아 = 학습자 대리인**: "국고 손실이 뭐예요?", "conditionnel을 왜 기사에 써요?" 같은 질문을 던지고 쥘리앵·카림·오브리 변호사가 쉬운 말로 풀어 줌 → 전문 어휘가 자연스럽게 설명됨
- **tu/vous 전환이 서사 장치**: 기자끼리는 tu, 취재원·공무원·변호사에게는 vous. 위장잠입 중에는 가짜 신분으로 vous를 쓰다가 정체가 들통나는 순간 상대가 tu로 바꾸는 등 **호칭 변화 = 긴장 신호**
- **장면 유형별 레지스터 대비**: 편집국 수다(구어·축약·속어) ↔ 공식 인터뷰(격식) ↔ 법률 검토(전문어) ↔ 위장 신분(사회 계층별 말투)

### 부별 기본 곡선

| 부 | 계절·기간 | 주 수준 | 사건 규모 | 중심 레지스터 |
|---|---|---|---|---|
| 1부 | 가을 (9~11월) | **A2 → B1** | 파리 시 재개발 입찰 비리 | 일상·편집국 구어, 기본 인터뷰 |
| 2부 | 겨울 (12~2월) | **B1** | 방산 기업 + 편집국 내부 첩자 | 의심·추궁·설득, conditionnel·subjonctif |
| 3부 | 봄 (3~5월) | **B1 → B2** | 사설 정보회사 위장잠입, 유럽 확장 | 격식 사교어 ↔ 사내 은어, 지역 프랑스어(벨기에·스위스) |
| 4부 | 여름 (6~9월) | **B2 (일부 C1)** | 국가적 음모, 소송·소환, 국제 공동보도 | 법률·연설·문어(passé simple), 고급 수사 |

### 화 안에서 섞는 규칙 (한 화 150턴 기준)

- **주 수준 약 105턴**, **복습 수준(한 단계 아래) 약 22턴**, **도전 수준(한 단계 위) 약 23턴**
- **레아의 대사는 주 수준 이하**, 오브리 변호사·생클레르·엘렌은 **한 단계 위** → "들어서 이해하는 수준"과 "말할 수 있는 수준"을 함께 노출
- 각 부에 **복습 화 1편**(축제·휴식 에피소드, 수준을 한 단계 낮춤): 1부 5화, 2부 5화, 3부 12화, 4부 7화
- 화 헤더 수준 표기: `초급~중급 (A2~B1)`, `중급 (B1)`, `중상급 (B1~B2)`, `상급 (B2)`, `상급 (B2~C1)`
- 턴 길이: A2는 1~2문장, B1은 2~3문장, B2는 3~4문장, C1은 4~5문장까지(연설·변론 장면은 한 턴이 길어도 됨)

### 한 화 150턴의 내부 구조 (5막 템플릿)

| 구간 | 턴 | 역할 |
|---|---|---|
| ① 도입 | 1~20 | 지난 화 이어받기, 장소·시간 소개, 그날의 과제 |
| ② 취재·전개 | 21~65 | 인터뷰·자료 분석·잠입 — 핵심 표현 대부분이 여기서 나옴 |
| ③ 위기 | 66~110 | 장애물(거절·들킬 위기·압력·의심) |
| ④ 반전·정리 | 111~140 | 새 사실 발견 또는 갈등 해소, 팀 내부 대화 |
| ⑤ 클리프행어 | 141~150 | 다음 화로 넘기는 한 방(메시지, 전화, 낯선 인물) |

## 4. 문법·표현 커리큘럼 (부별 누적)

| 부 | 핵심 문법 | 저널리즘 표현 |
|---|---|---|
| **1부** | tu/vous / 현재형·불규칙 동사(faire, prendre, devoir, pouvoir, vouloir) / 의문문 3형식(억양·est-ce que·도치) / 부정(ne…pas/plus/jamais/rien/personne) / passé composé vs imparfait / futur proche·passé récent(venir de) / 직·간접 목적보어 대명사 / y·en / 명령형 / 부분관사 / 비교급 / depuis·il y a·pendant / 관계대명사 qui·que·où / ne…que / il faut + inf. | 취재원·오프더레코드·반론권·팩트체크 기본 어휘, 숫자·금액·비율 읽기 |
| **2부** | futur simple / plus-que-parfait / **conditionnel présent**(공손·가정·**기사용 미확인 정보 « il aurait reçu »**) / **subjonctif présent**(il faut que, je veux que, avant que, bien que) / dont / lequel·auquel / 간접화법 / 이중 대명사(je le lui ai dit) / gérondif / 수동태 / se faire + inf. / si + présent → futur | 의심·추궁·부인·자백 표현, 계약·커미션·수출 어휘 |
| **3부** | **conditionnel passé** / si 가정문 3유형 / subjonctif passé / 시제 일치 / 현재분사·분사구문 / 강조 구문(c'est … qui/que) / ne explétif(avant qu'il ne…) / futur antérieur / 감정 + subjonctif / 레지스터: 격식(je vous en prie, permettez-moi) ↔ 구어·verlan(ouf, chelou, relou) / 벨기에·스위스 프랑스어(septante, nonante, dîner/souper) | 위장 신분·면접·사교 화법, 금융(비밀계좌·역외) 어휘, 데이터 유출 분석 |
| **4부** | **passé simple**(기록·옛 기사 읽기) / 명사화(style journalistique: « la démission du ministre ») / 논리 접속사(or, néanmoins, en revanche, dès lors) / 복합 화법 전달 / 법률 프랑스어(diffamation, bonne foi, présomption d'innocence, secret des sources, relaxe) / 연설·변론 수사 / 관용구·속담 / 양보·반박(quoique, quand bien même) | 법정·소환 조사·기자회견·성명서, 국제 공동보도 협상 |

## 7. 한 화의 포맷 (네덜란드어 시리즈와 동일, 150턴)

1. **제목 줄**: `N부 M화. Titre français (한글 제목)`
2. **수준 줄**: `수준: 중급 (B1) | 장소: … | 시간: …`
3. **핵심 표현 줄**: `핵심 표현: … · … · …` (본문에 실제로 등장해야 함)
4. **대화 150턴** — 턴 번호 없음
   ```
   Julien: Bon, on commence ?
   자, 시작할까?
   Léa: Oui, je suis prête.
   네, 준비됐어요.
   ```
   - 화자 이름: 대사 → 다음 줄에 한글 해석 (해석 줄에는 화자 표기 없음)
   - 지문은 `(chuchote)` / `(속삭이며)` 처럼 괄호로
   - 위장 중인 인물은 화자명을 실명으로 쓰고, 지문으로 가짜 신분을 표시: `Camille: (en tant que Sarah) …`
5. **📚 주요 단어** 표 (3열: 프랑스어 / 한글 발음 / 뜻), 약 15~18개
   - 명사는 관사 포함(`le dossier`, `la source`), 동사는 원형 + 과거분사(`prendre → pris`)
6. **📝 문법·표현 정리** 10~15항목, 예문과 한글 풀이
7. 부 마지막 화 끝에 **🎉 N부 완결** 요약 + 다음 부 예고
8. 화와 화 사이는 페이지 나눔, 기존 `tools/template.docx` 서식 사용

### 프랑스어 한글 발음 표기 원칙

|---|---|---|

| eu, œu | 외 | deux → 되, sœur → 쐬르 |

## 8. 제작 방식과 품질 관리

1. **기획 확정 → 샘플 1화(1부 1화) 먼저 작성 → 서식·난이도·분량(150턴) 확인** → 승인 후 본 작성
2. 화 단위 작성: 대사 150턴 + 해석 + 단어표 + 문법 정리를 한 번에 (`french/part1/ep01.txt` …)
3. 자동 점검: `tools/check_ep.py`를 턴 수 인자(100/150)를 받도록 확장해 공용 사용
   - 대사가 정확히 150턴인가 / 각 턴에 한글 해석이 있는가 / 턴 번호가 없는가
   - 핵심 표현이 본문에 등장하는가 / 단어표·문법 항목 수가 기준 이내인가
4. 설정 연속성 관리: 부마다 「새로 생긴 설정」을 10장에 기록 (가짜 신분 이름, 날짜, 금액, 서명 수 등)
5. 장르 특성상 **사실성 검수**: 프랑스 언론법(1881년 언론자유법, 반론권, 취재원 보호), 사법 절차 용어는 실제 제도에 맞게, 사건·인물은 가상으로
6. 진행 순서: 1부(15화) → 2부 → 3부 → 4부, 부별로 확인 후 다음 부로
