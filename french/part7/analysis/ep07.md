KO: (두 발코니 사이 빈 일 미터를 본다) 나중이라. (침묵) 난 «나중»이 좋아. 결국 온다는 뜻이잖아.
단어: le mètre = 미터 (m.) · vide = 빈 · aimer bien = 꽤 좋아하다 · vouloir dire = 뜻하다 · arriver = 일어나다, 오다
문법: "J'aime bien « plus tard »" = 표현 자체를 명사처럼 목적어로 / "Ça veut dire que ça arrivera" = vouloir dire que + 단순미래: 반드시 일어날 일 / 열린 결말의 여운
시제: regarde(regarder) = 직설법 현재(présent), 3인칭 단수 · aime(aimer) = 직설법 현재(présent), 1인칭 단수 · veut dire(vouloir dire) = 직설법 현재(présent), 3인칭 단수 · arrivera(arriver) = 단순미래(futur simple), 3인칭 단수
