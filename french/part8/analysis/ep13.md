KO: (밤 열한 시. 보도에서. 어머니에게 전화한다) 엄마? (침묵) 신문 나눠 줬어?
단어: le trottoir = 보도 (m.) · appeler = 전화하다 · distribuer = 나눠 주다 · le journal = 신문 (m.)
문법: "Tu as distribué les journaux ?" = 억양 의문문, journal의 복수 journaux / "Maman ?" = 전화 받았는지 확인하는 호칭
시제: appelle(appeler) = 직설법 현재(지문), 3인칭 단수 · as distribué(distribuer) = 복합과거, 2인칭 단수

## T148 | Marie
FR: Marie: (au téléphone ; on entend des voix, des rires, des verres) Les dix. (un silence) Et le maire en a demandé un onzième. Je lui ai dit : achète-le à Paris. (un silence) Tout le village est sur la place. Ils lisent ton article. À voix haute. (un silence) Ils disent le nom de ton père, Julien. À voix haute.
KO: (전화 너머. 목소리들, 웃음소리, 잔 부딪치는 소리) 열 부 전부. (침묵) 그리고 시장이 열한 번째를 달라더라. 파리에서 사라고 했지. (침묵) 온 마을이 광장에 나와 있어. 네 기사를 읽고 있어. 큰 소리로. (침묵) 너희 아버지 이름을 말하고 있어, 쥘리앵. 큰 소리로.
단어: le maire = 시장 (m.) · un onzième = 열한 번째 것 · acheter = 사다 · la place = 광장 (f.) · à voix haute = 큰 소리로
문법: "Les dix." = 앞 질문에 대한 생략 대답(열 부 전부) / "le maire en a demandé un onzième" = 수량대명사 en(신문 중에서) / "achète-le à Paris" = 반말 긍정 명령 + 대명사 뒤 하이픈 / "Ils disent le nom de ton père" = 현재형으로 지금 진행 중인 장면
시제: entend(entendre) = 직설법 현재(지문) · a demandé(demander) = 복합과거, 3인칭 단수 · ai dit(dire) = 복합과거, 1인칭 단수 · achète(acheter) = 명령법, 2인칭 단수 · est(être) = 직설법 현재, 3인칭 단수 · lisent(lire) = 직설법 현재, 3인칭 복수 · disent(dire) = 직설법 현재, 3인칭 복수

## T149 | Julien
FR: Julien: (il ferme les yeux ; un long silence ; derrière lui, à travers la vitrine du Zinc, l'équipe chante) Il aurait été fier.
KO: (눈을 감는다. 긴 침묵. 뒤로 르 쟁 유리창 너머 팀이 노래한다) 자랑스러워했을 거야.
단어: fermer les yeux = 눈을 감다 · la vitrine = 진열창, 유리창 (f.) · chanter = 노래하다 · fier, fière = 자랑스러운
문법: "Il aurait été fier" = 조건법 과거: 실현될 수 없는 과거 가정(살아 계셨다면 자랑스러워했을 것) / "à travers la vitrine" = ~을 통해 / "l'équipe chante" = 집합명사 + 단수 동사
시제: ferme(fermer), chante(chanter) = 직설법 현재(지문) · aurait été(être) = 조건법 과거(conditionnel passé), 3인칭 단수 — 비현실적 과거 가정

## T150 | Marie
FR: Marie: (doucement) Non, Julien. (un silence) Il est fier.
KO: (부드럽게) 아니야, 쥘리앵. (침묵) 자랑스러워하고 있어.
단어: doucement = 부드럽게 · fier = 자랑스러운
문법: "Non, Julien. Il est fier." = 앞 턴의 조건법 과거(aurait été)를 직설법 현재(est)로 고쳐 말함: 아버지가 '지금도' 자랑스러워한다는 강한 의미 / 시제 선택 자체가 메시지
시제: est(être) = 직설법 현재, 3인칭 단수 — 조건법 과거를 현재로 바꿔 지금의 사실로 단언
