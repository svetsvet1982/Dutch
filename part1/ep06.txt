# 1부 6화. Een zeldzame uitgave (희귀본 찾기)

## 문법·표현 정리
**현재완료 (불규칙 포함):** Ik heb iets gevonden. (뭔가를 찾았어요) · vinden → gevonden · zoeken → gezocht · kopen → gekocht. 과거분사는 보통 ge-로 시작합니다.
**과거형 입문 (zocht, stuurde):** Ik zocht naar een woord. (단어를 찾고 있었어요) · Ik stuurde u een bericht. 규칙동사는 어간 + -te/-de. 일상 대화에서는 완료형이 더 흔하지만 읽기 자료에는 과거형이 많이 나옵니다.
**연도 읽기:** 1865 = achttienhonderd vijfenzestig(18백 65). 영어처럼 두 자리씩 끊어 읽는 방식과 비슷하지만 "천" 대신 "백"으로 읽습니다. 2000년대는 tweeduizend… 입니다.
**큰 수:** 80 tachtig · 150 honderdvijftig · 180 honderdtachtig. 공백 없이 한 단어로 씁니다.
**전화번호 읽기:** nul zes(06) + 두 자리씩 끊어서 읽습니다. 번호를 받아 적을 때는 Langzamer, alstublieft.(더 천천히 말씀해 주세요)라고 부탁해 보세요.
**eerste / tweede:** 서수. eerste druk(초판) · tweede druk(재판) · de eerste keer(첫 번째). 서수는 eerste, tweede, derde, vierde… 이후엔 숫자 + -de/-ste.
**te veel / te duur:** te + 형용사/부사 = "너무 ~한". (Dat is te veel voor mij. 저한텐 너무 많아요) · te laat · te goedkoop.
**omdat, daarom:** Omdat ik het mooi vind. (아름다우니까요) Daarom stuurde ik u een bericht. (그래서 연락하려 했어요) omdat은 이유를 설명하는 접속사로 동사가 문장 끝에 갑니다. 2부에서 자세히 다룹니다.
**Dat zou geweldig zijn:** zou zijn = "~일 거예요". 가능성이나 바람을 공손하게 말합니다. 3부에서 가정법과 함께 다시 나옵니다.
**Ik beloof niets:** "약속은 못 해요." 부정 대명사 niets(아무것도 ~않다). Ik zie niets. · Ik weet niets.
**Het is niet dringend / Ik heb geen haast:** "급하지 않아요." haast = 서두름. in een haast zijn(서두르다).
**한국어와 다른 부정:** 문장에 niet을 쓰는 위치는 보통 문장 끝쪽입니다. (Dat wist ik niet. · Ik heb geen haast.)
**Weet u wat?:** "이렇게 하죠" 하고 제안을 꺼낼 때 쓰는 구어체 표현. 직역하면 "뭔지 아세요?"
**zelf:** Ik haal het zelf. (제가 직접 가져올게요) · Dan app ik u zelf. 재귀적으로 "직접"을 뜻합니다.
