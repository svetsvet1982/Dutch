## 문법·표현 정리
**Het waterpeil stijgt:** stijgen = 오르다. Het waterpeil stijgt. (수위가 올라요) · De prijzen stijgen. (가격이 올라요) 반대는 dalen / zakken. Het peil zakt. (수위가 내려가요)
**Code oranje:** 기상 경보 단계. Code geel(주의) · Code oranje(경계) · Code rood(위험). 네덜란드 기상청(KNMI)의 경보 체계입니다.
**Dat is mijn werk:** 직업을 자랑스럽게 말할 때. "그게 제 일이에요." Het is mijn werk. · Dat doe ik voor mijn werk. · Hij werkt bij een waterschap.
**De dijk houdt het:** houden = 유지하다, 버티다. De dijk houdt het. (둑은 버틴다) 반대는 De dijk houdt het niet. 속어로도 쓰입니다. (Het houdt het wel. 괜찮을 거야.)
**Ik ben trots op je:** trots zijn op + 사람. "네가 자랑스러워." 전치사 op과 함께 씁니다. Ik ben trots op mijn zus. Hij is trots op zijn werk.
**수동 맛보기:** De armen worden gevuld met water. (팔이 물로 채워져요) · Het wordt gecontroleerd. worden + 과거분사 = ~되다. 3부에서 자세히 배웁니다.
**ten opzichte van:** "~에 대하여, ~를 기준으로". Het waterpeil ten opzichte van NAP. (NAP 기준 수위) 약자로 t.o.v.라고 씁니다.
**als + 조건 (복습):** Als de dijken niet sterk genoeg zijn, is het gevaarlijk. 접속사 als = 만약 ~이면.
**waarschijnlijk / zeker:** waarschijnlijk(아마도) · zeker(확실히) · misschien(어쩌면) · vermoedelijk(추측컨대). 확신의 정도를 구분합니다. Ingenieurs zeggen nooit "zeker".
**Houd het in de gaten:** "계속 지켜봐." in de gaten houden = 감시하다. Houd de storm in de gaten. (폭풍을 지켜봐) 일상에서도 자주 씁니다.
**Goed gedaan!:** 과거분사 + 형용사. 수고했다는 칭찬. Goed gedaan, allemaal! (모두 잘했어요!) Goed bezig! (잘하고 있어요)
**Het is voorbij:** voorbij = 끝난. Het is voorbij. (끝났어요) 위기나 긴장이 끝났을 때.
**대명사 de vriendin:** 여자 친구. 연인 사이에도 vriendin을 쓰지만 문맥으로 구분합니다. 확실히 하려면 mijn vriendin(내 여자 친구), 친구는 een vriendin van mij.
**Hij zou trots zijn geweest:** zou + zijn + 과거분사 = "~했을 것이다". 과거에 대한 가정입니다. 3부에서 자세히 배웁니다.
**een opluchting:** opluchting = 안도감. Wat een opluchting! (정말 다행이야!) 걱정이 해소될 때.
