# 4부 13화. Het examen (NT2 시험)
수준: 중상급 (B1~B2) | 장소: 새 집, 시험장, 카페 't Hoekje | 시간: 10월 중순 (시험 전날 · 시험 당일 · 일주일 뒤)
핵심 표현: Ik ben geslaagd! · Ik heb er hard voor geleerd · Jij hebt me geholpen · Ik ben zo zenuwachtig · Het is zover

더 많은 주택이 지어져야 합니다. 그리고 정부가 집주인에게 더 엄격한 규칙을 정해야 해요.

흥미롭네요. 마지막 질문입니다. 어려운 결정을 내려야 했던 상황을 설명해 보세요.

왜요?

## 문법·표현 정리
**Ik ben geslaagd!:** slagen = 합격하다, 성공하다. 완료형은 zijn + geslaagd. Ik ben geslaagd voor mijn examen. (시험에 합격했어요) 반대는 zakken: Ik ben gezakt.
**Ik heb er hard voor geleerd:** er…voor 구조. leren voor = ~을 위해 공부하다. 이를 er voor로 분리. Ik heb er hard voor gewerkt. (그걸 위해 열심히 일했어요) hard = 열심히.
**Jij hebt me geholpen:** helpen의 완료형 heeft geholpen. 목적어 me(구어). Je hebt me veel geholpen. (많이 도와줬어요) 감사 표현의 기본형.
**Ik ben zo zenuwachtig:** zo + 형용사 = 너무 ~한. zenuwachtig = 긴장된. Ik ben nerveus. 도 같은 뜻.
**Het is zover:** zover zijn = 때가 되다. Het is zover! (때가 왔어요!) 기다리던 일이 시작될 때 씁니다.
**Waar denk je aan? / Ik denk erover na:** waar + 전치사로 의문. 대답에서는 er + 전치사. waaraan, waarover, waarvan. 질문: Waar denk je aan? 대답: Ik denk eraan. er+aan = eraan.
**Naar mijn mening:** "제 의견으로는". 구술·작문에서 의견을 시작할 때 씁니다. 비슷한 표현: Volgens mij…, Ik vind dat…
**Daardoor / daarom:** daardoor = 그 때문에(결과), daarom = 그러므로. Het tekort is groot. Daardoor zijn de prijzen hoog. 접속 부사로 어순이 도치됩니다.
**Er moeten meer woningen gebouwd worden:** 수동 + moeten. 조동사 + 과거분사 + worden. Er moet iets gedaan worden. (뭔가 이루어져야 해요) 사회 문제 논의에 자주 씁니다.
**Ik koos ervoor om…:** kiezen voor = ~을 택하다. ervoor + om te + 동사. Ik koos ervoor om te blijven. (남기로 했어요) 결정의 표현.
**Hierbij delen wij u mee dat…:** 격식 편지의 정형문. meedelen = 통지하다. 3부 3화의 Helaas moeten wij u meedelen과 같은 계열입니다.
**Dat is te veel eer:** "과분한 칭찬이에요." eer = 영광. 칭찬에 겸손하게 답할 때 씁니다.
**Een lege maag is een leeg hoofd:** 즉석 속담. 형용사 leeg 반복의 말놀이입니다. 일상 대화에서 농담으로 속담을 지어낼 때 씁니다.
