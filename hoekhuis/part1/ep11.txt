# 1부 11화. Opa Kees leert appen (오파 케이스, 메신저를 배우다)
난이도: A2~B1 | 장소: 오파 케이스의 거실(3층) | 시간: 4월 넷째 주 토요일 오후 2시~4시 (코닝스스펠런 다음 날)
등장인물: Opa Kees, Emre, Yasmin, Wilma
학습 포인트: 기술 어휘 · 설명·지시 화법 · 명령형

## 대화
(Zaterdagmiddag, twee uur. De woonkamer van Opa Kees. Op tafel ligt een nieuwe smartphone, nog in de doos. Emre zit naast Kees op de bank.)
Opa Kees : Daar ligt hij. Al tien dagen. Ik durf hem niet aan te raken.
Emre : Van wie heb je hem gekregen?
Opa Kees : Van Wilma. Voor mijn verjaardag. Ze zegt: "Pap, dan kun je met Fleur videobellen."
Emre : Dat is toch leuk? Dan zie je haar elke dag.
Opa Kees : Ja. Als ik weet hoe het werkt. Mijn oude telefoon had knopjes. Echte knopjes.
Emre : Geen probleem. Ik leer het je. Stap voor stap. Pak de doos maar.
Opa Kees : (pakt de telefoon uit) Zo. Hij is zo dun. Zo glad. Straks laat ik hem vallen.
Emre : Daarom krijg je een hoesje. Kijk, ik heb er een meegenomen. Blauw.
Opa Kees : Een hoesje. Een jasje voor een telefoon. Wat bedenken ze nog meer.
Emre : Oké. Stap één. Zet hem aan. Druk op het knopje aan de zijkant.
Opa Kees : Welk knopje? Er zijn er twee.
Emre : Het onderste. Nee, niet die. Die is voor het volume. Het andere.
Opa Kees : (drukt) Er gebeurt niks.
Emre : Je moet het even ingedrukt houden. Drie seconden. Tel maar.
Opa Kees : Eén... twee... drie... O! Hij gaat aan! Er staat "Hallo"!
Emre : Mooi! Nu moet je een taal kiezen. Scroll naar beneden. Zoek "Nederlands".
Opa Kees : Scrollen? Wat is scrollen?
Emre : Met je vinger over het scherm vegen. Van onder naar boven. Zo. Rustig.
Opa Kees : (veegt te hard) Ho! Hij gaat te snel! Ik zie Japans, Turks, Zweeds...
Emre : Turks! Dat is mijn taal. (lacht) Nee, rustig. Ga terug. Daar. Nederlands. Tik erop.
Opa Kees : Tikken. Met één vinger?
Emre : Met één vinger. Niet te hard. Het is geen deurbel.
Opa Kees : (tikt) Gelukt! Nederlands. Wat nu?
Emre : Nu moet je een pincode bedenken. Zes cijfers. Iets wat je makkelijk onthoudt.
Opa Kees : Mijn geboortedatum? Vijftien, vier, drieënveertig?
Emre : Nee! Dat is te makkelijk. Iedereen weet wanneer je jarig bent. De hele straat was op je feest.
Opa Kees : Dat is waar. Dan... het jaar van de Elfstedentocht. Negentien vijfentachtig. En nog twee cijfers.
Emre : Goed. Typ het in. En onthoud het. Schrijf het niet op een papiertje.
Opa Kees : (typt langzaam) Klaar. Hij vraagt het nog een keer.
Emre : Dat is om te controleren. Typ het nog een keer. Precies hetzelfde.
Opa Kees : (typt) Gelukt. Nu zie ik allemaal kleine plaatjes.
Emre : Dat zijn apps. Elk plaatje is een programma. Die groene is WhatsApp. Daarmee kun je appen.
Opa Kees : Appen. Dat zeggen de kleinkinderen ook altijd. "Opa, ik app je." En dan app ik niet terug.
Emre : Nu wel. Tik op de groene. Dan moet je je telefoonnummer invullen.
(Twintig minuten later. Yasmin komt binnen met een schaal koekjes.)
Yasmin : Hoe gaat het hier? Is Kees al een computerexpert?
Opa Kees : Nog niet, Yasmin. Maar ik heb al drie stappen gedaan. En ik heb maar één keer gevloekt.
Yasmin : (lacht) Hij is een goede leraar, hè?
Opa Kees : De beste. Strenger dan mijn juf vroeger. Hij zegt de hele tijd: "Niet zo hard drukken!"
Emre : Omdat je het scherm bijna kapot drukt.
Yasmin : Wat gaan jullie nu doen?
Emre : Een bericht sturen. Naar mama. Opa Kees, open WhatsApp. Tik op het plusje. Zoek "Yasmin".
Opa Kees : (zoekt) Yasmin... Daar! Je foto staat erbij. Met een zonnebril.
Emre : Tik onderaan in het witte vakje. Daar kun je typen. Typ "Hallo Yasmin".
Opa Kees : (typt heel langzaam) H... a... l... l... o. Waar is de spatie?
Emre : Die lange balk onderaan. Ja, die. Nu "Yasmin". Met een hoofdletter.
Opa Kees : Hoe maak ik een hoofdletter?
Emre : Tik eerst op het pijltje. Dan de letter.
Opa Kees : (typt) Klaar. "Hallo Yasmin." En nu?
Emre : Nu op het groene pijltje rechts. Dat is "versturen".
Opa Kees : (tikt) Weg. Hij is weg! Waar is hij heen?
Yasmin : (haar telefoon piept) Hier! Bij mij! "Hallo Yasmin."
Opa Kees : (verbaasd) Nu al? In één seconde? Vroeger duurde een brief drie dagen.
Yasmin : Ik stuur iets terug. Kijk maar.
Opa Kees : Er staat... een geel gezichtje. Het lacht. Met een hart.
Emre : Dat is een emoji. Je kunt ze ook zelf sturen. Tik op het gezichtje naast het vakje.
Opa Kees : (kijkt) Er zijn er honderden! Een koe, een fiets, een... wat is dit? Een aubergine?
Yasmin : (snel) Die moet je niet gebruiken, Kees.
Opa Kees : Waarom niet? Ik eet graag aubergine.
Emre : (giechelt) Neem gewoon de schaatser. Daar. Die past bij jou.
Opa Kees : (tikt) Een schaatser. Verstuurd. Dit is eigenlijk heel leuk.
Yasmin : Zie je wel? Je bent een natuurtalent, Kees.
(Kees' telefoon trilt. Er komt een bericht binnen.)
Opa Kees : Hé! Er komt iets binnen. Van een nummer dat ik niet ken.
Emre : Lees eens voor.
Opa Kees : (leest) "Hoi pap, dit is mijn nieuwe nummer. Mijn telefoon is kapot gevallen. Wil je dit nummer opslaan?" Wilma! Haar telefoon is kapot. Arme meid.
Yasmin : Wacht even, Kees. Niet te snel.
Opa Kees : Er komt nog een bericht. "Pap, ik moet vandaag een rekening betalen. Maar mijn bankapp werkt niet op de nieuwe telefoon. Kun je 950 euro voor me overmaken? Ik betaal het morgen terug." Negenhonderdvijftig euro? Dat is veel. Maar als ze het nodig heeft...
Emre : Opa Kees, stop. Niks doen. Dit is nep.
Opa Kees : Nep? Hoe weet je dat?
Emre : Dit gebeurt heel vaak. Ze doen alsof ze je kind zijn. Op school hebben we het geleerd.
Yasmin : Emre heeft gelijk. Dit heet de "hoi pap"-fraude. Of "hoi mam". Het is een bekende truc.
Opa Kees : Maar ze weten dat ik een dochter heb. Ze schrijven "pap".
Yasmin : Ze sturen het naar duizenden mensen. Iedereen heeft een vader of moeder. Ze gokken gewoon.
Emre : Er is een makkelijke test. Bel Wilma. Op haar oude nummer. Het echte nummer.
Opa Kees : Maar haar telefoon is toch kapot?
Emre : Dat zeggen zíj. Bel nou maar. Met video. Tik op het cameraatje bij Wilma.
Opa Kees : (tikt, het belt) Het belt... het belt...
Wilma : (op het scherm) Pap?! Pap, ben jij dat? Je belt met video!
Opa Kees : Wilma! Ik zie je! Je bent op het scherm!
Wilma : Ik zie jou ook! Een beetje van onderen. Ik zie vooral je neus. Hou de telefoon wat hoger.
Opa Kees : (houdt hem hoger) Zo? Wilma, is je telefoon kapot?
Wilma : Kapot? Nee. Ik bel je nu toch met mijn telefoon?
Opa Kees : En heb je geen nieuw nummer? En hoef je geen 950 euro?
Wilma : 950 euro? Pap! Heb je iets overgemaakt?!
Opa Kees : Nee, nee. Emre zei: niks doen. Het is nep, zegt hij.
Wilma : (zucht van opluchting) Gelukkig. Emre, dank je wel! Jij bent een held.
Emre : (naar het scherm) Graag gedaan!
Wilma : Pap, luister goed. Ik vraag je nooit geld via de app. Nooit. Afgesproken?
Opa Kees : Afgesproken, meisje. Nooit geld via de app.
Yasmin : En nu blokkeren we dat nummer. Kees, tik op het nummer bovenaan. Scroll naar beneden. Tik op "Blokkeren".
Opa Kees : (tikt) Geblokkeerd. Weg met die oplichters.
Yasmin : Je kunt het ook melden. Bij de Fraudehelpdesk. Dat doe ik straks wel voor je.
Wilma : Pap, ik moet gaan. Fleur wil zwaaien. Wacht. (een klein meisje verschijnt) Zeg eens dag tegen opa Kees!
Opa Kees : (zachtjes) Dag, Fleur. Dag, lieverd. (zwaait)
Wilma : Ze zwaait terug! Zie je het? Dag pap! Tot snel!
Opa Kees : (de video stopt; hij kijkt even naar het scherm) Ik heb haar gezien. Mijn achterkleindochter. Vandaag. Op een zaterdag. Zomaar.
Emre : Zie je wel? Daarom heb je die telefoon.
Opa Kees : Jongen, jij hebt me vandaag twee keer gered. Eén keer van de oplichters. En één keer van mijn eigen domheid.
Yasmin : Nog één regel, Kees. Klik nooit op een link van iemand die je niet kent.
Opa Kees : Een link? Wat is een link?
Emre : Een blauw stukje tekst. Als je erop tikt, ga je naar een website. Soms een nepwebsite.
Opa Kees : (kijkt naar zijn scherm) Zoals deze? "Uw pakket kon niet worden bezorgd. Klik hier." Er is een blauw stukje.
Emre : Ja! Precies zo! Verwijderen!
Opa Kees : Maar ik heb niks besteld. Ik bestel nooit iets.
Yasmin : Precies. Dan weet je het al. Nep. Houd je vinger op het bericht. Dan zie je een prullenbakje. Tik erop.
Opa Kees : (doet het) Weg. In de prullenbak. Ik leer snel, hè?
Emre : Heel snel. Nu de laatste stap: een foto maken. Tik op het cameraatje.
Opa Kees : (houdt de telefoon omhoog) Ik zie... mezelf. Wat een oude man.
Emre : Dat is de selfiecamera. Draai hem om. Tik op het rondje met de pijltjes.
Opa Kees : Nu zie ik jou. En Yasmin. Lach eens!
Yasmin : (lacht) Cheese!
Opa Kees : Waarom zeggen jullie "cheese"? Wij zeiden vroeger "kaas".
Emre : Dan zeggen we "kaas"! Eén, twee, drie!
Yasmin en Emre : Kaas!
Opa Kees : (tikt) Gelukt! Een foto. Jullie lachen allebei. Ik stuur hem naar Wilma.
Emre : Hoe doe je dat? Weet je het nog?
Opa Kees : WhatsApp. Wilma. Het paperclipje. De foto. Het groene pijltje. (tikt) Verstuurd!
Emre : Helemaal zelf! Opa Kees, je kunt appen!
Opa Kees : Dank je, meester Emre. Hoeveel ben ik je schuldig?
Emre : Niks. Maar volgende winter... leer jij mij schaatsen. Echt schaatsen. Afgesproken?
Opa Kees : (steekt zijn hand uit) Afgesproken. Als het vriest. Dat beloof ik je.

## 낭독 포인트
- g/ch: gekregen, gelukt, geblokkeerd, gered, gebruiken, gevloekt, geleerd, gelijk / vroeger, echt, lach → g[ɣ]·ch[x]. "Gelukt!"는 이 화의 감탄사 — 목 안쪽 g를 짧게 긁고 끝 t를 분명히.
- ui: duizenden, gebruiken, luister → ui[œy]. "Ze sturen het naar duizenden mensen"에서 duizenden과 sturen(uu)을 대비해 읽는다.
- ij/ei: pijltje, pijltjes, zijkant, cijfers, verwijderen, schrijven, vijftien(ij) / kleine, kleinkinderen, meisje, meid, eigen, domheid, zeiden(ei) → 같은 소리 '에이'. 어미 -lijk는 [lək]: makkelijk, eigenlijk, gelijk.
- eu: leuk, neus, deurbel, euro, Fleur, gebeurt → eu[øː]. "Ik zie vooral je neus"와 "Het is geen deurbel"을 둥근 입으로.
- oe/uu: hoesje, groene, zoek, koe, moeder, gevloekt, hoef, vroeger(oe[u]) / stuur, verstuurd, duurde(uu[yː]). "Verstuurd!"의 uu를 길게.
- sch: scherm, schaatser, schaatsen, schrijf, schrijven, schuldig, school → s+ch[sx]. "Hoeveel ben ik je schuldig?"의 schuldig.
- 명령형 리듬: Zet hem aan. / Druk op het knopje. / Tik erop. / Typ het in. / Lees eens voor. / Bel nou maar. — 동사를 맨 앞에 두고 짧고 분명하게, 끝을 내린다. eens·maar·nou·even을 붙이면 부드러워진다.
- 외래어: smartphone, app, appen, scrollen, emoji, selfie, link는 영어식으로 읽되 네덜란드어 동사 어미를 붙인다: ik app, je scrolt, gescrold.
- 억양: 케이스는 기계 앞에서 느리고 조심스럽게, 성공하면 크게("Gelukt!"). 에므레는 선생님처럼 또박또박. "Opa Kees, stop. Niks doen."은 단호하게 끊는다. 빌마와 영상통화하는 장면은 반갑고 들뜬 목소리로.

## 학습 포인트 정리
- 기술 어휘: de smartphone, het hoesje, het scherm, het knopje, het volume, de pincode, de app, appen, het bericht, versturen, de spatie, de hoofdletter, het pijltje, de emoji, videobellen, de link, de prullenbak, verwijderen, blokkeren, melden, de selfiecamera, het paperclipje(첨부).
- 동작 동사: aanzetten, (ingedrukt) houden, tikken, vegen, scrollen, typen, invullen, opslaan, overmaken(송금하다), omdraaien.
- 명령형(je/jij 기준 = 동사 어간): Zet hem aan! / Druk op … / Tik erop. / Typ het in. / Kijk maar. / Bel nou maar. / Hou(d) de telefoon hoger. / Lach eens!
- 부정 명령: Niet zo hard drukken! / Niks doen. / Schrijf het niet op een papiertje. / Klik nooit op een link.
- 순서대로 설명하기: Stap één. / Eerst …, dan … / Nu moet je … / Daarna … / De laatste stap.
- 부드럽게 시키기: eens(Lees eens voor), maar(Pak de doos maar), even(Wacht even), nou(Bel nou maar).
- 사기 경고: Dit is nep. / Het is een bekende truc. / Ze doen alsof ze je kind zijn. / Ik vraag je nooit geld via de app. / Klik nooit op een link van iemand die je niet kent.
- 네덜란드 생활 정보: "hoi mam/hoi pap"-fraude는 실제로 흔한 메신저 사기 수법이고, Fraudehelpdesk에 신고할 수 있다.

## 속어 노트
- 아이(에므레)가 함께 있어 [속어] 태그가 붙는 거친 표현은 쓰지 않았다. 케이스가 "한 번 욕했다"고 말만 한다.
- gevloekt (일상어): vloeken(욕하다)의 과거분사. "Ik heb maar één keer gevloekt."
- oplichters (일상어): '사기꾼들'. 거친 말이 아니라 뉴스에서도 쓰는 단어.
- nep (구어): '가짜'. "Dit is nep." / een nepwebsite.
- aubergine 이모지: 케이스는 모르지만, 메신저에서 성적인 뜻으로 쓰이는 일이 있어 야스민이 급히 말린다 — 이모지에도 숨은 뜻이 있다는 문화 메모.

## 한글 해석
(토요일 오후 2시. 오파 케이스의 거실. 탁자 위에 아직 상자에 든 새 스마트폰이 놓여 있다. 에므레가 소파에서 케이스 옆에 앉아 있다.)
오파 케이스 : 저기 있어. 벌써 열흘째. 손대기가 겁나.
에므레 : 누가 줬어요?
오파 케이스 : 빌마가. 생일 선물로. "아빠, 그럼 플뢰르랑 영상통화할 수 있잖아요." 하더라.
에므레 : 좋잖아요? 그럼 매일 볼 수 있잖아요.
오파 케이스 : 그래. 쓸 줄 알면 말이지. 옛날 전화기는 버튼이 있었어. 진짜 버튼.
에므레 : 문제없어요. 제가 가르쳐 줄게요. 한 단계씩. 상자 집어 봐요.
오파 케이스 : (전화기를 꺼낸다) 어디 보자. 엄청 얇네. 엄청 미끄럽고. 금방 떨어뜨리겠어.
에므레 : 그래서 케이스를 씌우는 거예요. 봐요, 제가 하나 가져왔어요. 파란색으로.
오파 케이스 : 케이스라. 전화기 입히는 외투. 별걸 다 만드는군.
에므레 : 좋아요. 1단계. 전원을 켜요. 옆에 있는 버튼을 눌러요.
오파 케이스 : 어느 버튼? 두 개가 있는데.
에므레 : 아래쪽 거요. 아니, 그거 말고요. 그건 음량 버튼이에요. 다른 거요.
오파 케이스 : (누른다) 아무 일도 안 일어나는데.
에므레 : 좀 길게 누르고 있어야 해요. 3초요. 세어 봐요.
오파 케이스 : 하나... 둘... 셋... 오! 켜졌다! "Hallo"라고 떴어!
에므레 : 좋아요! 이제 언어를 골라야 해요. 아래로 스크롤해요. "Nederlands"를 찾아요.
오파 케이스 : 스크롤? 스크롤이 뭐야?
에므레 : 손가락으로 화면을 쓸어 넘기는 거예요. 아래에서 위로. 이렇게요. 천천히요.
오파 케이스 : (너무 세게 쓸어 넘긴다) 워! 너무 빨리 가! 일본어, 터키어, 스웨덴어...
에므레 : 터키어! 내 언어다. (웃는다) 아니, 천천히요. 다시 돌아가요. 거기. 네덜란드어. 그걸 톡 눌러요.
오파 케이스 : 톡 누른다. 손가락 하나로?
에므레 : 손가락 하나로요. 너무 세게 말고요. 초인종이 아니에요.
오파 케이스 : (톡 누른다) 됐다! 네덜란드어. 이제 뭐 해?
에므레 : 이제 비밀번호를 정해야 해요. 숫자 여섯 개. 기억하기 쉬운 걸로요.
오파 케이스 : 내 생일? 15, 4, 43?
에므레 : 안 돼요! 너무 쉬워요. 할아버지 생일은 다 알잖아요. 동네 사람 전부가 생일잔치에 왔었는데.
오파 케이스 : 그건 그렇군. 그럼... 엘프스테던토흐트 해. 1985. 그리고 숫자 두 개 더.
에므레 : 좋아요. 입력해요. 그리고 꼭 외워요. 종이에 적어 두지 말고요.
오파 케이스 : (천천히 입력한다) 다 했다. 한 번 더 물어보는데.
에므레 : 확인하려는 거예요. 한 번 더 입력해요. 똑같이요.
오파 케이스 : (입력한다) 됐다. 이제 작은 그림들이 잔뜩 보이네.
에므레 : 그게 앱이에요. 그림 하나하나가 프로그램이에요. 그 초록색이 왓츠앱이에요. 그걸로 메시지를 보내요.
오파 케이스 : 앱으로 보낸다. 손주들도 맨날 그 말을 하지. "할아버지, 메시지 보낼게요." 그러고 나는 답장을 안 해.
에므레 : 이제는 하게 될 거예요. 초록색을 눌러요. 그다음에 전화번호를 입력해야 해요.
(20분 뒤. 야스민이 쿠키 접시를 들고 들어온다.)
야스민 : 여긴 어때? 케이스는 벌써 컴퓨터 전문가야?
오파 케이스 : 아직은 아니야, 야스민. 그래도 벌써 세 단계 했어. 그리고 욕은 딱 한 번밖에 안 했어.
야스민 : (웃는다) 좋은 선생님이지?
오파 케이스 : 최고야. 내 어릴 적 선생님보다 엄해. 계속 그래. "그렇게 세게 누르지 마요!"
에므레 : 화면을 부술 기세로 누르니까 그렇죠.
야스민 : 이제 뭐 할 거야?
에므레 : 메시지 보내기요. 엄마한테요. 오파 케이스, 왓츠앱 열어요. 더하기 표시를 눌러요. "Yasmin"을 찾아요.
오파 케이스 : (찾는다) 야스민... 저기 있다! 사진도 같이 있네. 선글라스 쓰고.
에므레 : 아래쪽 하얀 칸을 눌러요. 거기서 글자를 쓸 수 있어요. "Hallo Yasmin"이라고 써요.
오파 케이스 : (아주 천천히 입력한다) H... a... l... l... o. 띄어쓰기는 어디 있어?
에므레 : 아래에 있는 긴 막대요. 네, 그거요. 이제 "Yasmin". 대문자로요.
오파 케이스 : 대문자는 어떻게 만들어?
에므레 : 먼저 화살표를 누르고요. 그다음에 글자요.
오파 케이스 : (입력한다) 다 했다. "Hallo Yasmin." 이제는?
에므레 : 이제 오른쪽에 초록 화살표를 눌러요. 그게 "보내기"예요.
오파 케이스 : (누른다) 갔다. 사라졌어! 어디로 간 거야?
야스민 : (휴대폰이 울린다) 여기! 나한테 왔어! "Hallo Yasmin."
오파 케이스 : (놀라서) 벌써? 1초 만에? 옛날엔 편지 하나가 사흘 걸렸는데.
야스민 : 답장 보낼게. 봐 봐.
오파 케이스 : 뭐가 왔는데... 노란 얼굴이네. 웃고 있어. 하트랑 같이.
에므레 : 그게 이모지예요. 할아버지도 직접 보낼 수 있어요. 칸 옆에 있는 얼굴 모양을 눌러요.
오파 케이스 : (본다) 수백 개가 있네! 소, 자전거, 그리고... 이건 뭐야? 가지?
야스민 : (재빨리) 그건 쓰지 마, 케이스.
오파 케이스 : 왜? 난 가지 좋아하는데.
에므레 : (킥킥 웃는다) 그냥 스케이트 타는 사람으로 해요. 저거요. 할아버지랑 어울려요.
오파 케이스 : (누른다) 스케이트 타는 사람. 보냈다. 이거 사실 꽤 재밌네.
야스민 : 거봐? 타고났네, 케이스.
(케이스의 전화기가 진동한다. 메시지가 들어온다.)
오파 케이스 : 어! 뭐가 들어왔어. 모르는 번호에서.
에므레 : 읽어 봐요.
오파 케이스 : (읽는다) "아빠, 나 새 번호야. 휴대폰이 떨어져서 고장 났어. 이 번호 저장해 줄래?" 빌마! 전화기가 고장 났대. 불쌍한 것.
야스민 : 잠깐만, 케이스. 너무 서두르지 마.
오파 케이스 : 메시지가 하나 더 왔어. "아빠, 오늘 청구서를 내야 하는데. 새 폰에서 은행 앱이 안 돼. 950유로만 보내 줄 수 있어? 내일 갚을게." 950유로? 큰돈인데. 그래도 그 애한테 필요하다면...
에므레 : 오파 케이스, 멈춰요. 아무것도 하지 마요. 이건 가짜예요.
오파 케이스 : 가짜? 그걸 어떻게 알아?
에므레 : 이런 일 진짜 자주 있어요. 자식인 척하는 거예요. 학교에서 배웠어요.
야스민 : 에므레 말이 맞아. 이걸 "안녕 아빠" 사기라고 해. 아니면 "안녕 엄마". 유명한 수법이야.
오파 케이스 : 그런데 내가 딸이 있는 걸 알잖아. "아빠"라고 썼어.
야스민 : 수천 명한테 보내는 거야. 누구나 아빠나 엄마는 있잖아. 그냥 찍어 보는 거지.
에므레 : 쉬운 확인 방법이 있어요. 빌마 아줌마한테 전화해요. 옛날 번호로요. 진짜 번호로요.
오파 케이스 : 그런데 전화기가 고장 났다며?
에므레 : 그건 걔네가 하는 말이고요. 그냥 걸어 봐요. 영상으로요. 빌마 아줌마 옆에 카메라 모양을 눌러요.
오파 케이스 : (누르자 신호가 간다) 신호 간다... 신호 간다...
빌마 : (화면에) 아빠?! 아빠, 아빠 맞아요? 영상통화를 걸었네요!
오파 케이스 : 빌마! 네가 보인다! 화면에 나왔어!
빌마 : 나도 아빠 보여요! 좀 아래에서 보여요. 코만 보여요. 전화기를 좀 더 높이 들어요.
오파 케이스 : (높이 든다) 이렇게? 빌마, 너 전화기 고장 났니?
빌마 : 고장이요? 아니요. 지금 내 전화로 아빠한테 걸고 있잖아요?
오파 케이스 : 그럼 새 번호도 없고? 950유로도 필요 없고?
빌마 : 950유로? 아빠! 뭐 송금했어요?!
오파 케이스 : 아니, 아니. 에므레가 그러더라: 아무것도 하지 말라고. 가짜래.

에므레 : (화면을 향해) 천만에요!
빌마 : 아빠, 잘 들어요. 나는 메신저로 절대 돈 달라고 안 해요. 절대. 약속?
오파 케이스 : 약속하마, 얘야. 메신저로 돈은 절대 안 보내.
야스민 : 그리고 이제 그 번호를 차단하자. 케이스, 위에 있는 번호를 눌러. 아래로 내려. "차단"을 눌러.
