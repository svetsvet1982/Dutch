# 1부 10화. Bitterballen en borrelhapjes (비터발과 안주)
난이도: A2~B1 | 장소: 카페 't Hoekje | 시간: 4월 넷째 주 목요일 저녁 6시~7시 반 (코닝스스펠런 전날)
등장인물: Bram, Karin, Daan, Marieke, Yasmin
학습 포인트: 음식 어휘 · 맛 표현 · 취향 비교

## 대화
(Donderdagavond, zes uur. Café 't Hoekje. Op de lange tafel staan tien schaaltjes en borden. Naast elk bord ligt een kaartje met een nummer. Bram heeft een schort voor.)
Bram : Welkom, welkom! Vanavond is de grote proeverij!
Daan : Proeverij? Ik dacht: gratis eten.
Bram : Het is allebei. Maar jullie moeten wel cijfers geven. Van één tot tien.
Marieke : Pap, waarom eigenlijk? De oude kaart is toch goed?
Bram : De oude kaart is twintig jaar oud. Net als het café. Tijd voor iets nieuws.
Karin : En de huur gaat omhoog. Dus we moeten meer verdienen. Dat is de echte reden.
Bram : Karin! Dat hoeven de klanten niet te weten.
Yasmin : Wij zijn geen klanten, Bram. Wij zijn buren. Wij weten alles al.
Bram : (zucht) Dat is waar. Goed. Pak een pen. Hier zijn de kaartjes.
Daan : Wat is nummer één?
Bram : Nummer één: de klassieke bitterbal. Met rundvlees. Het oude recept.
Karin : Pas op. Ze komen net uit de frituur. Ze zijn gloeiend heet.
Daan : Ach, ik kan wel tegen een beetje warmte. (neemt een hele bitterbal in zijn mond)
Marieke : Daan, nee! Niet in één keer!
Daan : (met open mond) Ha... ha... Godver [속어], heet! Heet! Water!
Karin : (geeft hem een glas water) Zei ik toch. Elke keer weer.
Daan : (drinkt) Zo. Mijn tong is weg. Maar hij was lekker. Denk ik.
Bram : Denk je? Je moet het weten!
Daan : Een acht. De smaak was goed. Maar de temperatuur was een twee.
Yasmin : Je moet eerst een hapje nemen. Dan blazen. Zo. (bijt een klein stukje) Mm. Romig vanbinnen. Knapperig vanbuiten.
Marieke : Precies. Zoals een bitterbal moet zijn. Een acht voor mij ook.
Bram : Mooi. De klassieker blijft. Nummer twee: de vegetarische bitterbal. Met paddenstoelen.
Daan : Vegetarisch? In een bruin café?
Marieke : Pap, eindelijk! Ik vraag dit al drie jaar.
Bram : Ik luister heus wel naar mijn dochter. Soms. Proef maar.
Marieke : (proeft) O, die is lekker. Lekkerder dan de gewone, vind ik.
Daan : Lekkerder? Dat kan niet. (proeft) Hm. Hij is goed. Maar hij is niet beter.
Yasmin : Ik proef tijm. En een beetje knoflook. Heel fijn.
Karin : Ik vind hem een beetje flauw. Er mag meer zout in.
Bram : Meer zout. Ik schrijf het op. (schrijft) Nummer drie: ossenworst. Met piccalilly.
Marieke : Ossenworst! Typisch Amsterdams.
Yasmin : Wat is ossenworst eigenlijk? Ik heb het nog nooit geproefd.
Bram : Rauw rundvlees. Gekruid, een beetje gerookt. Een echte Amsterdamse specialiteit.
Yasmin : Rauw? Hm. Ik weet het niet. (proeft voorzichtig) O. Het valt mee. Het is niet vies.
Bram : Niet vies? Dat is geen compliment, Yasmin.
Yasmin : Sorry. Ik bedoel: het is beter dan ik dacht. Maar het is niet mijn favoriet.
Daan : Voor mij een negen. Met veel piccalilly. Lekker zuur.
Karin : De piccalilly is wel erg geel. Dat vinden toeristen raar.
Bram : Toeristen vinden alles raar. Nummer vier: kaasstengels.
Marieke : (pakt er een) Mm, krokant. Maar ze zijn een beetje vettig.
Karin : Dat is de bedoeling. Vet is smaak.
Marieke : Vet is ook calorieën, Karin.
Karin : Op een borrel tellen we niet. Dat zegt Ria ook altijd.
Daan : Een zeven. Lekker, maar niet bijzonder. Die koop je ook in de supermarkt.
Bram : (beledigd) Deze zijn zelfgemaakt! Door Karin!
Daan : O. Dan een acht. (lacht)
Karin : Te laat, Daan. Ik heb het gehoord.
Bram : Nummer vijf. Een verrassing. Van Yasmin.
Yasmin : (zet een bord neer) Sigara börek. Turkse rolletjes. Met feta en peterselie.
Daan : Ze zien eruit als loempia's. Maar dan dunner.
Yasmin : Het deeg is filodeeg. Heel dun. En dan bak je ze kort. Mijn moeder maakt ze altijd op feestjes.
Marieke : (proeft) O. Mijn. God. Dit is het lekkerste van de hele avond.
Bram : (proeft) Hm... Zout. Romig. Knapperig. Yasmin, dit is fantastisch.
Karin : Lekkerder dan de bitterballen. Sorry, Bram.
Bram : Nee, je hebt gelijk. Dit is beter. Een negen. Nee, een negenenhalf.
Yasmin : (lacht) Een negenenhalf? Van een Nederlander? Dat gebeurt nooit.
Marieke : Klopt. Een tien geven we alleen aan God. En aan Johan Cruijff.
Daan : Mag ik er nog een? Of twee?
Yasmin : Neem er maar drie. Ik heb er veertig gemaakt.
Bram : Veertig? Yasmin, wil je ze voor het café maken? Ik betaal je natuurlijk.
Yasmin : Voor het café? Elke week?
Bram : Elke week. Vijftig stuks. Dan zetten we ze op de kaart. "Yasmins rolletjes."
Yasmin : Dat moet ik even uitrekenen. Hoeveel ik nodig heb. Wat het kost.
Daan : Natuurlijk. Ze is boekhouder. Eerst de cijfers, dan de rolletjes.
Yasmin : Precies. Maar ik vind het een leuk idee. Ik denk erover na.
Bram : Afgesproken. Nummer zes: leverworst met mosterd.
Marieke : Pap, leverworst? Dat eet niemand onder de zeventig.
Bram : Kees eet het. Kees is mijn beste klant.
Marieke : Kees is drieëntachtig. Dat bedoel ik.
Daan : (proeft) Ik vind het eigenlijk wel lekker. Maar ik heb liever ossenworst.
Karin : En ik heb liever helemaal niks. Leverworst is niet te eten.
Bram : (lacht) Oké, oké. De leverworst gaat eraf. Behalve op dinsdag, voor Kees.
Yasmin : Nummer zeven? Wat is dat? Dat ziet er groen uit.
Bram : Dat is... hummus. Met olijfolie en paprikapoeder. Met stukjes brood.
Marieke : Hummus! Pap, je bent echt modern geworden!
Bram : Ik heb het op YouTube gezien. In tien minuten gemaakt.
Daan : (proeft) Hm. Het smaakt een beetje... naar niks.
Yasmin : (proeft) Er mist citroen. En komijn. En meer knoflook.
Bram : Citroen, komijn, knoflook. (schrijft) Yasmin, jij bent de chef, zie ik.
Yasmin : Nee hoor. Mijn moeder is de chef. Ik ben maar de assistent.
Karin : Volgende keer nodigen we je moeder uit.
Yasmin : Dan kookt ze voor de hele straat. Dan stop je haar niet meer.
Marieke : Pap, wat vind jij eigenlijk het lekkerst? Van alles?
Bram : Eerlijk? De bitterbal. Altijd de bitterbal. Daar ben ik mee opgegroeid.
Karin : En de hummus? Die heb je toch zelf gemaakt?
Bram : De hummus is... een experiment. Een mislukt experiment.
Daan : Een eerlijke kok. Dat zie je niet vaak.
Bram : Nummer acht: olijven. Nummer negen: oude kaas. Nummer tien: nootjes.
Daan : Die ken ik al. Die zijn altijd goed. Een zeven, een acht en een zes.
Marieke : Waarom een zes voor de nootjes?
Daan : Omdat het nootjes zijn. Nootjes zijn altijd een zes. Voldoende, maar niet spannend.
Karin : (verzamelt de kaartjes) Zo. Laat eens zien. Wie heeft er gewonnen?
Bram : Lees maar voor, Karin.
Karin : Op de eerste plaats: de sigara börek van Yasmin. Gemiddeld een negen.
Yasmin : Echt? Wat leuk!
Karin : Op de tweede plaats: de klassieke bitterbal. Een acht. Op de derde plaats: de ossenworst.
Bram : Mooi. Amsterdam doet het goed.
Karin : Op de laatste plaats: de leverworst. Met een vier.
Bram : Een vier! Arme leverworst.
Marieke : En de vegetarische bitterbal? Waar staat die?
Karin : Op de vierde plaats. Een zevenenhalf. Met een opmerking: meer zout.
Marieke : Dan gaat hij op de kaart, pap. Beloofd?
Bram : Beloofd. Met meer zout.
Daan : Wat wordt de prijs van een borrelplank? Met alles erop?
Bram : Ik dacht: veertien vijftig. Is dat te duur?
Yasmin : Hoeveel stuks zitten erop?
Bram : Zes bitterballen, zes rolletjes, ossenworst, kaas en olijven.
Yasmin : Dan is veertien vijftig redelijk. Bij de andere cafés betaal je meer.
Daan : En je krijgt er gezelligheid gratis bij.
Bram : Precies. Gezelligheid is gratis. Bier niet.
Karin : Nog een laatste vraag. Hoe noemen we de nieuwe borrelplank?
Marieke : De Hoekjesplank?
Daan : De Twintig-Jaar-Plank? Voor het jubileum?
Yasmin : De Burenplank. Omdat de buren hem samen hebben gemaakt.
Bram : (denkt even na) De Burenplank. Ja. Die is het.
Karin : De Burenplank. Ik schrijf hem morgen op het krijtbord.
Marieke : Proost! Op de Burenplank!
Daan : Op de Burenplank! (neemt nog een bitterbal) Au! Godver [속어]! Alweer heet!
Yasmin : (lacht) Daan, je leert het ook nooit.
Daan : Nee. Maar dat is juist het leuke. Zonder pijn geen bitterbal.

## 낭독 포인트
- g/ch: gloeiend, gekruid, gerookt, geproefd, gewone, gemiddeld, gezelligheid, gratis, groen / lekkerder, echt, zelfgemaakt의 g → g[ɣ]·ch[x]. "gezelligheid"는 g가 두 번 나오는 네덜란드어의 대표 단어.
- ui: vanbuiten, bruin, gekruid, uitrekenen, eruit, juist, luister → ui[œy]. "Ze zien eruit als loempia's"의 eruit를 한 덩어리로. 이름 Cruijff[krœyf]는 옛 철자 ij가 붙은 ui.
- ij/ei: tijm, fijn, olijven, olijfolie, komijn, prijs, pijn, proeverij, krijtbord, bijzonder(ij) / allebei, gezelligheid, specialiteit, zei(ei) → 같은 소리 '에이'. 어미 -lijk는 [lək]: eindelijk, eigenlijk, redelijk, natuurlijk, gelijk.
- eu: leuk, het leuke, heus, gebeurt → eu[øː]. "Wat leuk!"을 둥근 입으로. jubileum의 eu는 e+u로 따로 읽는다[jybiˈleːjʏm].
- oe/uu: proeverij, proef, geproefd, gloeiend, citroen, paddenstoelen, moeder, toeristen, voldoende, loempia's(oe[u]) / zuur, duur, frituur, temperatuur(uu[yː]). "Lekker zuur"의 zuur를 입술을 오므려 길게.
- sch: schrijf → s+ch[sx]. 단 형용사 어미 -isch는 [is]: typisch, fantastisch, vegetarisch(e) — "Typisch Amsterdams"를 [ˈtipis]로.
- 숫자(성적): een acht, een negenenhalf(9.5), een zevenenhalf(7.5), een zes. 네덜란드 학교 성적은 1~10점이고 5.5 이상이 합격(voldoende). 10점은 거의 주지 않는다.
- 억양: 단이 뜨거운 비터발을 먹는 장면은 입을 벌린 채 "Ha... ha..."를 과장되게. 마리커의 "O. Mijn. God."는 단어마다 끊어서. 카린의 순위 발표는 시상식 사회자처럼.

## 학습 포인트 정리
- 음식 어휘: de bitterbal, het borrelhapje, de borrelplank, de ossenworst(암스테르담식 소고기 생소시지), de leverworst, de kaasstengel, de olijf, de oude kaas, de nootjes, de piccalilly(노란 채소 피클 소스), de mosterd, de hummus, het filodeeg, de frituur, rundvlees, paddenstoelen, tijm, knoflook, komijn, citroen, peterselie.
- 맛 표현: lekker / heerlijk / vies(맛없는·더러운) / flauw(싱거운) / te zout / zuur / romig / knapperig·krokant / vettig / gekruid / Het smaakt naar niks. / Er mist citroen. / Er mag meer zout in.
- 완곡하게 평가하기: Het valt mee.(생각보다 괜찮다) / Het is niet vies. / Het is niet mijn favoriet. / Niet bijzonder. / Voldoende, maar niet spannend.
- 취향 비교: Lekkerder dan de gewone, vind ik. / Hij is niet beter. / Ik heb liever ossenworst. / Dit is het lekkerste van de hele avond. / Ik vind het eigenlijk wel lekker.
- 숫자로 평가하기: Een acht voor mij. / Gemiddeld een negen. / Op de eerste/tweede/laatste plaats.
- 가격 판단: Is dat te duur? / Dan is veertien vijftig redelijk. / Bij de andere cafés betaal je meer.

## 속어 노트
- Godver [속어]: godverdomme('빌어먹을')를 줄인 말. 뜨거운 걸 먹다 데었을 때처럼 순간적으로 튀어나온다. 친구 사이에서도 거친 편이고, 손님·아이·격식 장면이나 신앙이 있는 사람 앞에서는 쓰지 않는다 → 대신 "Au!" 또는 "Jeetje, heet!".
- niet te eten (구어): '못 먹을 정도다'. 거친 말은 아니지만 요리한 사람 앞에서는 실례.
- Zonder pijn geen bitterbal (말장난): 속담 "Zonder pijn geen fijn"(고생 없이는 즐거움도 없다)을 비튼 농담.

## 한글 해석
(목요일 저녁 6시. 카페 't 훅여. 긴 테이블 위에 작은 그릇과 접시 열 개가 놓여 있다. 접시마다 옆에 번호 카드가 있다. 브람은 앞치마를 둘렀다.)
브람 : 어서 와, 어서 와! 오늘 밤은 대시식회야!
단 : 시식회요? 저는 공짜 밥인 줄 알았는데요.
브람 : 둘 다야. 대신 점수는 매겨야 해. 1점부터 10점까지.
마리커 : 아빠, 근데 왜? 옛날 메뉴도 괜찮잖아.
브람 : 옛날 메뉴는 20년 됐어. 카페랑 똑같이. 새로운 게 필요할 때야.
카린 : 그리고 월세가 오르잖아요. 그러니까 더 벌어야죠. 그게 진짜 이유예요.
브람 : 카린! 그건 손님들이 알 필요 없잖아.
야스민 : 우리는 손님 아니에요, 브람. 이웃이에요. 다 알고 있어요.
브람 : (한숨) 그건 그렇네. 좋아. 펜 들어. 여기 카드.
단 : 1번은 뭐예요?
브람 : 1번: 정통 비터발. 소고기. 옛날 레시피.
카린 : 조심해요. 방금 튀김기에서 나왔어요. 펄펄 끓어요.
단 : 에이, 저 뜨거운 거 좀 잘 먹어요. (비터발 하나를 통째로 입에 넣는다)
마리커 : 단, 안 돼! 한입에 먹으면 안 돼!
단 : (입을 벌린 채) 하... 하... 젠장, 뜨거워! 뜨거워! 물!
카린 : (물 한 잔을 건넨다) 내가 말했잖아요. 매번 이래.
단 : (마신다) 휴. 혀가 없어졌어요. 그래도 맛있었어요. 아마도요.
브람 : 아마도? 확실히 말해야지!
단 : 8점. 맛은 좋았어요. 근데 온도는 2점이에요.
야스민 : 먼저 조금만 베어 먹어야지. 그리고 후후 불고. 이렇게. (작게 한 입 문다) 음. 속은 크리미하고. 겉은 바삭하고.
마리커 : 바로 그거야. 비터발은 그래야지. 나도 8점.
브람 : 좋아. 클래식은 남긴다. 2번: 채식 비터발. 버섯으로.
단 : 채식이요? 브라운 카페에서요?
마리커 : 아빠, 드디어! 3년째 부탁했잖아.
브람 : 나도 딸 말은 들어. 가끔. 먹어 봐.
마리커 : (맛본다) 오, 맛있다. 내 생각엔 보통 것보다 더 맛있어.
단 : 더 맛있다고요? 말도 안 돼. (맛본다) 흠. 괜찮네요. 그래도 더 낫진 않아요.
야스민 : 타임 맛이 나. 마늘도 조금. 아주 좋네.
카린 : 나는 좀 싱거워요. 소금 더 넣어도 돼요.
브람 : 소금 더. 적어 둘게. (적는다) 3번: 오선보르스트. 피칼릴리 곁들여서.
마리커 : 오선보르스트! 완전 암스테르담식이네.
야스민 : 오선보르스트가 뭐예요? 한 번도 안 먹어 봤어요.
브람 : 생소고기야. 양념해서 살짝 훈제한 거. 진짜 암스테르담 특산이지.
야스민 : 생고기요? 흠. 모르겠다. (조심스럽게 맛본다) 아. 생각보다 괜찮네요. 맛없진 않아요.
브람 : 맛없진 않다? 그건 칭찬이 아니잖아, 야스민.
야스민 : 미안해요. 제 말은: 생각보다 맛있다는 거예요. 근데 제 최애는 아니에요.
단 : 저는 9점. 피칼릴리 듬뿍 얹어서. 새콤해서 맛있어요.
카린 : 피칼릴리가 너무 노랗긴 해요. 관광객들이 이상하게 생각하더라고요.
브람 : 관광객들은 뭐든 이상하게 생각해. 4번: 치즈 스틱.
마리커 : (하나 집는다) 음, 바삭하다. 근데 좀 느끼해.
카린 : 그게 원래 그런 거예요. 기름이 맛이에요.
마리커 : 기름은 칼로리이기도 하죠, 카린.
카린 : 술자리에선 칼로리 안 세요. 리아도 맨날 그렇게 말해요.
단 : 7점. 맛있는데 특별하진 않아요. 이건 슈퍼에서도 사잖아요.
브람 : (발끈해서) 이건 직접 만든 거야! 카린이!
단 : 아. 그럼 8점이요. (웃는다)
카린 : 늦었어요, 단. 다 들었어요.
브람 : 5번. 깜짝 메뉴. 야스민이 만든 거.
야스민 : (접시를 내려놓으며) 시가라 뵈렉이에요. 터키식 말이요. 페타 치즈랑 파슬리를 넣었어요.
단 : 춘권처럼 생겼네요. 근데 더 가늘어요.
야스민 : 반죽은 필로 반죽이야. 아주 얇아. 그리고 짧게 튀기면 돼. 우리 엄마가 잔치 때마다 만들어.
마리커 : (맛본다) 와. 세상에. 이게 오늘 밤 제일 맛있어.
브람 : (맛본다) 흠... 짭짤하고. 크리미하고. 바삭하고. 야스민, 이거 끝내준다.
카린 : 비터발보다 맛있어요. 미안해요, 브람.
브람 : 아니, 네 말이 맞아. 이게 더 나아. 9점. 아니, 9.5점.
야스민 : (웃는다) 9.5점? 네덜란드 사람이? 그런 일은 절대 없는데.
