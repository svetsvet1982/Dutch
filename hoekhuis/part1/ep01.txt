# 1부 1화. Een gewone dinsdag in 't Hoekje ('t 훅여의 평범한 화요일)
난이도: A2~B1 | 장소: 카페 't Hoekje (요르단, 운하변 건물 1층) | 시간: 3월 말 화요일 아침 7시 15분~8시 40분
등장인물: Bram, Karin, Daan, Opa Kees, Marieke
학습 포인트: 인사 · 시간 · 주문 · 현재형 · V2 어순

## 대화
(Dinsdagochtend, eind maart. Het regent. Bram doet de deur van 't Hoekje van het slot.)
Bram : Zo. Goedemorgen, Hoekje. Daar gaan we weer.
Karin : (komt binnen met haar fiets aan de hand) Morgen, Bram! Ben ik te laat?
Bram : Nee hoor, je bent precies op tijd. Het is kwart over zeven.
Karin : Mooi. Wat een kutweer [속어], zeg. Het regent alweer.
Bram : Het is maart, Karin. In maart regent het altijd.
Karin : Ja ja. Zet jij de koffie, of doe ik dat?
Bram : Doe jij de koffie maar. Ik doe het krijtbord.
Karin : Wat schrijf je vandaag op?
Bram : Soep van de dag: tomatensoep. En appeltaart, natuurlijk.
Karin : Natuurlijk. Geen dinsdag zonder appeltaart.
Bram : Zeg, hoe schrijf je "uitsmijter"? Met ij of met ei?
Karin : Met ij, Bram. Lange ij. Twintig jaar café en dat weet je nog niet?
Bram : Ik weet het heus wel. Ik test je gewoon.
Karin : Tuurlijk. (lacht) Wat kost de uitsmijter nu?
Bram : Negen vijftig. Alles wordt duurder, hè.
Karin : Ja, vertel mij wat. M'n huur ook.
Bram : (hangt het bord buiten op) Zo. Hangt het recht?
Karin : Iets naar links. Ja, zo. Perfect.
Bram : Mooi. Dan zijn we open. Om half acht precies.
Karin : Wie komt er als eerste, denk je? Daan of Kees?
Bram : Daan. Die heeft om negen uur al een klant.
Karin : Zullen we wedden? Een euro.
Bram : Afgesproken. Een euro op Daan.
(Om vijf over half acht gaat de deur open. Daan komt binnen, nat van de regen.)
Daan : Goedemorgen, allemaal! Koffie, Bram, alsjeblieft. Een grote.
Bram : (tegen Karin) Zie je wel? Die euro is van mij.
Karin : Balen. Morgen, Daan. Een grote koffie, komt eraan.
Daan : Hebben jullie gewed? Op mij?
Bram : Ja. Dankzij jou heb ik een euro gewonnen.
Daan : Dan krijg ik toch een gratis koekje? (grijnst)
Karin : Haha, nee hoor. Een koekje kost vijftig cent.
Daan : Nou ja, zeg. Wat een service.
Bram : Hoe laat ga jij vandaag open?
Daan : Om negen uur. Maar om half negen komt er al een klant.
Karin : Zo vroeg? Wie dan?
Daan : Yasmin. Met de nieuwe fiets van Emre.
Bram : Heeft Emre een nieuwe fiets? Wat leuk.
Daan : Ja, zo'n mooie blauwe. Hij is tien, dus het is z'n eerste grote fiets.
Karin : En wat moet jij eraan doen?
Daan : Het zadel moet hoger. En de bel doet het niet.
Bram : Een fiets zonder bel, in Amsterdam? Dat kan niet.
Daan : Nee, dat kan echt niet. (drinkt) Mm, lekkere koffie, Karin.
Karin : Dank je. Ik heb 'm met liefde gemaakt.
Daan : Dat proef ik. Zeg, Emre moet wel een goed slot kopen.
Bram : Hoezo?
Daan : Nou, mooie nieuwe fietsen worden hier snel gestolen.
Karin : Ja, dat is waar. Mijn fiets is al drie keer gestolen.
Daan : Drie keer? Wat een pech, joh.
Karin : Nee hoor, geen pech. Ik had gewoon slechte sloten.
Bram : Wil je er nog iets bij, Daan? Een broodje?
Daan : Ja, lekker. Een broodje kaas, graag.
Karin : Jong of oud?
Daan : Oud, graag. Met mosterd.
Bram : Komt eraan. Ga lekker zitten.
(Om tien voor acht gaat de deur weer open. Opa Kees komt langzaam binnen, met zijn wandelstok.)
Opa Kees : Brr. Goedemorgen. Is het hier lekker warm?
Bram : Goedemorgen, meneer Kees! Kom binnen. Uw tafel is vrij.
Opa Kees : Meneer Kees? Bram, je kent me al twintig jaar.
Bram : Ja, maar u bent onze oudste klant. Dat verdient respect.
Opa Kees : Zeg toch gewoon "je". Ik voel me zo oud met "u".
Bram : Goed dan. Wat wil je drinken, Kees?
Opa Kees : Zie je wel, dat klinkt veel beter. Een koffie verkeerd, graag.
Karin : Met een koekje erbij?
Opa Kees : Twee koekjes, als het mag. Ik ben bijna jarig.
Daan : Echt waar? Wanneer dan?
Opa Kees : Over twee weken. Op de vijftiende. Dan word ik drieëntachtig.
Karin : Drieëntachtig! Dat moeten we vieren, Kees.
Opa Kees : Ach, ik hoef geen feest. Een taartje is genoeg.
Bram : Geen feest? Dat dacht ik niet. Het wordt een echte verjaardag.
Opa Kees : Met een kring stoelen, zeker? En iedereen feliciteren?
Bram : Natuurlijk. Zo doen we dat in Nederland.
Opa Kees : (lacht) Goed, goed. Maar niet te veel mensen.
Daan : Ik neem een cadeautje mee. Een nieuwe bel voor je fiets.
Opa Kees : Ik fiets niet meer, jongen. Maar ik schaats nog wel. In m'n hoofd.
Karin : In je hoofd? (lacht) Hoe gaat dat?
Opa Kees : Ik doe m'n ogen dicht. En dan sta ik weer op het ijs.
Daan : Nou, met dit weer vriest het niet meer.
Opa Kees : Nee. Vroeger hadden we echte winters. Nu alleen regen.
Bram : Ja, en wind. Altijd wind.
Opa Kees : Wind is goed. Die houdt je jong.
Daan : (kijkt op zijn telefoon) Wat? Het is al twintig over acht!
Karin : Rustig maar. Yasmin komt pas om half negen.
Daan : Ja, maar ik moet de werkplaats nog opendoen. Wat krijg je van me, Bram?
Bram : Een koffie en een broodje. Zes euro.
Daan : Kan ik pinnen?
Bram : Tuurlijk. Hier is het pinapparaat.
Daan : (pint) Zo. Tot straks, allemaal! Dag Kees!
Opa Kees : Dag jongen. Rij voorzichtig.
Daan : Ik loop alleen maar de trap op, Kees. (lacht) Tot zo!
(Om vijf voor half negen komt Marieke haastig binnen, met haar laptoptas. Haar telefoon zit aan haar oor.)
Marieke : Ja... ja, prima. Ik bel je straks terug. Doei. (hangt op) Morgen, pap.
Bram : Goedemorgen, schat. Ga je even zitten?
Marieke : Nee, geen tijd. Mag ik een cappuccino om mee te nemen?
Karin : Komt eraan. Goedemorgen, Marieke.
Marieke : Morgen, Karin. Sorry, ik ben een beetje gehaast.
Bram : Een beetje? Je bent altijd gehaast.
Marieke : Ik heb om negen uur een overleg. En om tien uur nog een.
Opa Kees : Goedemorgen, Marieke.
Marieke : Goedemorgen, meneer Kees. Hoe gaat het met u?
Opa Kees : Geen "meneer" en geen "u" meer. Dat is de nieuwe regel.
Marieke : Sinds wanneer?
Bram : Sinds vanochtend. Kees heeft het zelf besloten.
Marieke : (lacht) Oké. Hoe gaat het met je, Kees?
Opa Kees : Goed, dank je. Maar jij werkt te hard, meisje.
Marieke : Ja, dat zegt iedereen. Maar het werk stopt niet.
Bram : Het werk stopt nooit. Daarom moet jij soms stoppen.
Marieke : Pap, begin niet weer, alsjeblieft.
Karin : Hier, je cappuccino. Met extra schuim.
Marieke : Je bent een schat, Karin. Wat krijg je van me?
Bram : Niks. Die is van het huis.
Marieke : Dank je, pap. (geeft hem een kus) Ik moet echt gaan.
Bram : Kom je vanavond eten?
Marieke : Ik weet het nog niet. Ik app je, oké?
Bram : Oké. Fiets voorzichtig, het is glad.
Marieke : Ja, pap. Doei! (ze rent naar buiten)
(De deur valt dicht. Het is even stil in het café.)
Opa Kees : Ze lijkt op jou, Bram. Altijd druk.
Bram : Op mij? Ik ben toch helemaal niet druk.
Karin : (lacht hard) Jij? Jij praat de hele dag!
Bram : Praten is niet druk. Praten is gezellig.
Opa Kees : Twintig jaar 't Hoekje. En het is nog steeds gezellig.
Bram : Twintig jaar... Dat is dit jaar al, hè? Daar moeten we iets mee doen.
Karin : Eerst Kees z'n verjaardag. Dan jouw feest.
Bram : (kijkt naar buiten, naar de regen) Goed. Maar vandaag is het gewoon dinsdag.

## 낭독 포인트
- g/ch: goedemorgen, gewoon, gezellig, dag, gestolen, vroeg, echt의 g·ch는 목 안쪽에서 긁는 [x]·[ɣ] 소리. 암스테르담 사람은 약간 부드럽게 낸다. "Goedemorgen"은 실제 구어에서 "Morgen"으로 줄여 빠르게 말한다.
- ui: uitsmijter, buiten, schuim, duurder의 uu와 대비. ui[œy]는 입술을 둥글게 한 채 '아우'와 '어이' 사이를 미끄러뜨린다.
- ij/ei: uitsmijter, tijd, rij, lijkt(ij) / meisje, met ei(ei). 두 철자는 발음이 같다. 그래서 브람이 철자를 묻는 장면이 성립한다 — 낭독할 때 같은 소리로 읽을 것.
- eu: Wat leuk, heus wel → eu[øː]는 입술을 둥글게 한 '외'에 가깝다.
- oe/uu: goed, koekje, doe, Hoekje(oe[u]) / duurder, huur, Tuurlijk(uu[yː]) — 입술을 오므린 채 혀를 앞으로 내밀어 [y]를 길게.
- sch: schat, schuim, schaats, schrijf → s + ch[sx]. 영어 sk처럼 읽지 않는다.
- 축약: 't Hoekje[ət], m'n[mən], z'n[zən], 'm[əm], zo'n[zoːn], Tuurlijk(natuurlijk), Morgen(goedemorgen), Doei.
- 억양: "Zie je wel?"(그것 봐) — 끝을 내리며 의기양양하게. "Nou ja, zeg."는 장난스러운 불만, zeg에 강세. "Hè"는 끝을 올려 동의를 구한다. 오파 케이스는 느리고 낮게, 마리커는 빠르고 높게 읽어 인물을 구별한다.

## 학습 포인트 정리
- 인사: Goedemorgen / Morgen (아침), Dag (만날 때·헤어질 때 모두), Tot straks / Tot zo (곧 봐요), Doei (친한 사이의 안녕).
- 시간: kwart over zeven(7:15), half acht(7:30 — '8시를 향한 절반'), vijf over half acht(7:35), tien voor acht(7:50), twintig over acht(8:20), vijf voor half negen(8:25). half + 다음 시각에 주의.
- 주문(손님): Koffie, alsjeblieft. / Een broodje kaas, graag. / Mag ik een cappuccino om mee te nemen? / Wat krijg je van me?(얼마예요?) / Kan ik pinnen?(카드로 낼 수 있어요?)
- 주문(가게): Komt eraan.(곧 나갑니다) / Wil je er nog iets bij? / Jong of oud?(치즈 숙성도) / Die is van het huis.(서비스예요)
- 현재형: ik werk, jij werkt, hij werkt / werk jij?(도치되면 -t 탈락) — "Zet jij de koffie?", "Kom je vanavond eten?"
- V2 어순: 첫 자리에 무엇이 오든 동사는 두 번째. "Om half negen komt er al een klant." "In maart regent het altijd." "Vandaag is het gewoon dinsdag."
- 호칭 전환: Bram이 Kees에게 u → je로 바꾸는 장면. 친해지자는 신호는 "Zeg maar je" / "Zeg toch gewoon je".
- 담화표지: zo(자), nou(글쎄·자), hoor(부정·긍정을 부드럽게: Nee hoor), joh, zeg, hè, toch, gewoon.

## 속어 노트
- kutweer [속어]: '거지 같은 날씨'. 친구·동료끼리 날씨에 투덜댈 때 흔히 쓴다. 손님, 아이, 어른, 격식 장면 앞에서는 쓰지 않는다 → 대신 "Wat een rotweer" 또는 "Wat een weer, zeg".
- balen (속어 태그 없음, 가벼운 구어): '아 짜증 나·아쉽다'. 친구 사이 어디서나 무난하다. 격식 장면에서는 "Wat jammer".

## 한글 해석
(3월 말 화요일 아침. 비가 온다. 브람이 't 훅여의 문을 연다.)
브람 : 자. 좋은 아침, 훅여. 또 시작이다.
카린 : (자전거를 끌고 들어오며) 좋은 아침, 브람! 나 늦었어요?
브람 : 아니, 딱 맞춰 왔어. 7시 15분이야.
카린 : 좋네요. 날씨 진짜 거지 같네요. 또 비 와요.
브람 : 3월이잖아, 카린. 3월엔 늘 비가 와.
카린 : 네, 네. 커피는 사장님이 내릴래요, 아니면 내가 할까요?
브람 : 커피는 네가 해. 나는 칠판 할게.
카린 : 오늘은 뭐라고 쓸 거예요?
브람 : 오늘의 수프: 토마토 수프. 그리고 사과파이, 당연히.
카린 : 당연하죠. 사과파이 없는 화요일은 없으니까.
브람 : 그런데 '아위츠메이터르' 어떻게 써? ij야, ei야?
카린 : ij예요, 브람. 긴 ij. 카페를 20년이나 하고도 그걸 아직 몰라요?
브람 : 당연히 알지. 그냥 너 시험해 본 거야.
카린 : 그러시겠죠. (웃는다) 아위츠메이터르는 지금 얼마예요?
브람 : 9.50유로. 다 비싸지잖아, 그치.
카린 : 누가 아니래요. 우리 집 월세도요.
브람 : (칠판을 밖에 내건다) 자. 똑바로 걸렸어?
카린 : 살짝 왼쪽으로. 네, 그렇게. 완벽해요.
브람 : 좋아. 그럼 개점이다. 7시 반 정각.
카린 : 누가 제일 먼저 올 것 같아요? 단이요, 케이스요?
브람 : 단. 걔는 9시에 벌써 손님이 있거든.
카린 : 내기할래요? 1유로.
브람 : 좋아. 단에 1유로.
(7시 35분에 문이 열린다. 단이 비에 젖은 채 들어온다.)
단 : 다들 좋은 아침! 커피요, 브람, 부탁해요. 큰 걸로.
브람 : (카린에게) 거봐? 그 1유로는 내 거야.
카린 : 아 아쉽다. 좋은 아침, 단. 큰 커피, 금방 나가요.
단 : 내기했어요? 나 가지고?
브람 : 응. 네 덕분에 1유로 땄어.
단 : 그럼 쿠키 하나는 공짜로 주시는 거죠? (씩 웃는다)
카린 : 하하, 아니거든요. 쿠키는 50센트예요.
단 : 아니 참 나. 서비스 한번 대단하네.
브람 : 너 오늘 몇 시에 가게 열어?
단 : 9시요. 근데 8시 반에 벌써 손님이 와요.
카린 : 그렇게 일찍? 누군데요?
단 : 야스민이요. 에므레 새 자전거 가지고.
브람 : 에므레가 새 자전거 생겼어? 잘됐네.
단 : 네, 엄청 예쁜 파란 거요. 걔가 열 살이라 처음 타는 큰 자전거예요.
카린 : 그럼 그걸 어떻게 손봐야 하는데요?
단 : 안장을 올려야 하고요. 벨이 안 울려요.
브람 : 벨 없는 자전거라고, 암스테르담에서? 그건 안 되지.
단 : 네, 그건 진짜 안 되죠. (마신다) 음, 커피 맛있네요, 카린.
카린 : 고마워요. 사랑을 담아 내렸거든요.
단 : 맛에서 느껴져요. 그런데 에므레는 좋은 자물쇠를 꼭 사야 해요.
브람 : 왜?
단 : 아니, 예쁜 새 자전거는 여기서 금방 도둑맞거든요.
카린 : 맞아요, 진짜. 내 자전거는 벌써 세 번 도둑맞았어요.
단 : 세 번? 운도 없네요.
카린 : 아니, 운이 아니에요. 그냥 자물쇠가 형편없었던 거죠.
브람 : 뭐 더 먹을래, 단? 샌드위치 하나?
단 : 네, 좋죠. 치즈 샌드위치 하나 주세요.
카린 : 영 치즈요, 숙성 치즈요?
단 : 숙성으로요. 머스터드 넣어서.
브람 : 금방 나가. 편하게 앉아 있어.
(7시 50분에 문이 다시 열린다. 오파 케이스가 지팡이를 짚고 천천히 들어온다.)
오파 케이스 : 으, 추워. 좋은 아침. 여기는 따뜻한가?
브람 : 좋은 아침입니다, 케이스 어르신! 들어오세요. 늘 앉으시는 자리 비어 있어요.
오파 케이스 : 케이스 어르신? 브람, 자네 나를 안 지 20년이야.
브람 : 네, 그래도 저희 제일 오래된 손님이시잖아요. 존중해 드려야죠.
오파 케이스 : 그냥 편하게 '너'라고 해. '당신'이라고 하면 너무 늙은 기분이야.
브람 : 좋아요, 그럼. 뭐 마실래, 케이스?
오파 케이스 : 거봐, 훨씬 듣기 좋잖아. 코피 페르케르트(라테) 한 잔 주게.
카린 : 쿠키도 같이 드려요?
오파 케이스 : 괜찮다면 두 개. 곧 내 생일이거든.
단 : 정말요? 언제요?
오파 케이스 : 2주 뒤. 15일. 그날로 여든세 살이 되지.
카린 : 여든세 살! 그건 축하해야죠, 케이스.
오파 케이스 : 에이, 파티는 됐어. 작은 케이크 하나면 충분해.
브람 : 파티가 없다고요? 그건 안 되지. 제대로 된 생일잔치 할 거야.
오파 케이스 : 의자 빙 둘러놓고, 그렇지? 다 같이 돌아가며 축하 인사하고?
브람 : 당연하지. 네덜란드에선 그렇게 하잖아.
오파 케이스 : (웃는다) 알았어, 알았어. 그래도 사람은 너무 많지 않게.
단 : 저는 작은 선물 가져갈게요. 자전거용 새 벨이요.
오파 케이스 : 난 이제 자전거 안 타, 이 사람아. 그래도 스케이트는 아직 타지. 머릿속에서.

오파 케이스 : 눈을 감아. 그러면 다시 얼음 위에 서 있지.
단 : 근데 이런 날씨면 이제 얼음은 안 얼겠어요.
오파 케이스 : 그렇지. 옛날엔 진짜 겨울이 있었는데. 지금은 비만 와.
브람 : 맞아, 그리고 바람. 늘 바람.
오파 케이스 : 바람은 좋은 거야. 사람을 젊게 해 주거든.
단 : (휴대폰을 본다) 뭐야? 벌써 8시 20분이네!

단 : 네, 그래도 작업장 문을 아직 안 열었어요. 얼마예요, 브람?
브람 : 커피 한 잔이랑 샌드위치. 6유로.
단 : 카드 돼요?
브람 : 당연하지. 여기 카드 단말기.
단 : (카드로 계산한다) 됐다. 다들 이따 봐요! 안녕히 계세요, 케이스!
오파 케이스 : 잘 가게. 조심해서 타고 가.
단 : 계단만 올라가면 되는데요, 케이스. (웃는다) 이따 봐요!
(8시 25분, 마리커가 노트북 가방을 들고 바삐 들어온다. 휴대폰을 귀에 대고 있다.)
마리커 : 네... 네, 좋아요. 이따 다시 전화할게요. 안녕. (전화를 끊는다) 좋은 아침, 아빠.
브람 : 좋은 아침, 우리 딸. 잠깐 앉을래?
마리커 : 아니, 시간 없어. 카푸치노 테이크아웃으로 하나 돼?
카린 : 금방 나가요. 좋은 아침, 마리커.
마리커 : 좋은 아침, 카린. 미안, 내가 좀 바빠서.
브람 : 좀? 넌 늘 바쁘잖아.
마리커 : 9시에 회의가 있어. 10시에 또 하나 있고.
오파 케이스 : 좋은 아침, 마리커.
마리커 : 좋은 아침이에요, 케이스 할아버지. 잘 지내세요?
오파 케이스 : '할아버지'도 '당신'도 이제 그만. 그게 새 규칙이야.
마리커 : 언제부터요?
브람 : 오늘 아침부터. 케이스가 직접 정했어.
마리커 : (웃는다) 알았어요. 잘 지내, 케이스?
오파 케이스 : 잘 지내, 고마워. 그런데 넌 일을 너무 많이 해, 얘야.
마리커 : 네, 다들 그렇게 말해요. 그런데 일이 안 끝나요.
브람 : 일은 절대 안 끝나. 그러니까 너는 가끔 멈춰야 해.
마리커 : 아빠, 또 시작하지 마, 제발.
카린 : 여기, 카푸치노. 거품 듬뿍.
마리커 : 카린, 당신은 천사야. 얼마예요?
브람 : 됐어. 서비스야.
마리커 : 고마워, 아빠. (아빠에게 뽀뽀한다) 진짜 가야 돼.
브람 : 오늘 저녁 먹으러 올래?
마리커 : 아직 모르겠어. 문자할게, 알았지?
브람 : 그래. 자전거 조심해, 길 미끄러워.
마리커 : 네, 아빠. 안녕! (밖으로 뛰어나간다)
(문이 닫힌다. 카페 안이 잠시 조용해진다.)
