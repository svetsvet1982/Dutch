# 1부 2화. De fiets is weg (자전거가 없어졌다)
난이도: A2~B1 | 장소: 건물 앞 운하변 → 레인바안스흐라흐트 경찰서 → 단의 자전거 수리점 | 시간: 1화 이틀 뒤 목요일, 아침 8시~저녁
등장인물: Emre, Yasmin, Daan, Agent Visser
학습 포인트: 과거 사건 서술 · 완료시제(hebben/zijn) · 신고 표현

## 대화
(Donderdagochtend, acht uur. Voor het Hoekhuis aan de gracht. Emre komt met zijn rugzak naar buiten.)
Emre : Mam! Mam, kom eens! Mijn fiets is weg!
Yasmin : (komt de trap af) Wat zeg je? Weg?
Emre : Ja, weg! Hij stond hier. Bij het hek.
Yasmin : Weet je het zeker? Heb je goed gekeken?
Emre : Ja! Ik heb overal gekeken. Hier, daar, bij de brug.
Yasmin : Wanneer heb je hem hier neergezet?
Emre : Gisteren. Na school. Om vier uur, denk ik.
Yasmin : En heb je hem op slot gezet?
Emre : Natuurlijk! Ik heb hem op slot gezet. Echt waar.
Yasmin : Met welk slot? Het ringslot of de ketting?
Emre : Eh... het ringslot.
Yasmin : Alleen het ringslot? Emre, waar is de ketting dan?
Emre : Die ligt boven, in de gang. Hij is zo zwaar, mam.
Yasmin : (zucht) O, canım. Daan heeft het nog gezegd.
Emre : Ik weet het. (bijna in tranen) Ik ben zo stom.
Yasmin : Nee, jij bent niet stom. De dief is gemeen.
Emre : Ik heb hem pas een week! Eén week!
Yasmin : Ik weet het, schat. Kom hier. (knuffelt hem)
Emre : Ik huil niet, hoor. Er zit gewoon iets in m'n oog.
Yasmin : Ja, ja. Kom, je moet naar school. Vandaag ga je lopen.
Emre : Lopen? Dat duurt twintig minuten!
Yasmin : Dan ben je er om twintig over acht. Ruim op tijd.
(Daan komt net uit 't Hoekje, met een beker koffie in zijn hand.)
Daan : Goedemorgen, Aksoys! Wat is er? Jullie kijken zo somber.
Emre : Mijn fiets is gestolen, Daan.
Daan : Nee! De blauwe? Die ik dinsdag heb afgesteld?
Emre : Ja. Hij is weg.
Daan : Balen, man. Wanneer is het gebeurd?
Yasmin : Vannacht, denken we. Emre heeft hem gisteren om vier uur hier neergezet.
Daan : En vanochtend was hij weg.
Emre : Ja. Ik ben naar buiten gegaan, en... niks.
Daan : Welk slot heb je gebruikt?
Emre : (kijkt naar de grond) Alleen het ringslot.
Daan : Hm. En heb je hem vastgezet? Aan het hek of aan een paal?
Emre : Nee... Ik was moe. En ik had haast.
Daan : Tja. Dan tillen ze hem gewoon op en lopen ze weg. In twee seconden.
Emre : Wat gemeen!
Daan : Ja, heel gemeen. Maar er is nog één kleine kans.
Emre : Welke kans?
Daan : Misschien heeft de gemeente hem weggehaald. Dat gebeurt soms.
Yasmin : De gemeente? Waarom?
Daan : Als een fiets op een verkeerde plek staat. Dan gaat hij naar het fietsdepot.
Yasmin : Hoe kan ik dat controleren?
Daan : Online, met het framenummer. Dat staat op de fiets, maar ook op de bon. Heb je de bon nog?
Yasmin : Ja, ik heb er een foto van gemaakt. (zoekt op haar telefoon) Hier.
Emre : En als hij niet in het depot staat?
Daan : Dan moeten jullie aangifte doen. Bij de politie.
Yasmin : Kan dat vandaag nog?
Daan : Ja, online of op het bureau. Het bureau is hier vlakbij, aan de Lijnbaansgracht.
Yasmin : Dan gaan we vanmiddag, na school. Goed, Emre?
Emre : Goed. Maar nu moet ik lopen. (zucht diep)
Daan : Hé, kop op, kerel. We vinden wel een oplossing.
Emre : Beloofd?
Daan : Beloofd. Ga nou maar, anders kom je te laat.
(Die middag, half vier. Het politiebureau aan de Lijnbaansgracht. Yasmin en Emre staan aan de balie.)
Agent Visser : Goedemiddag. Waarmee kan ik u helpen?
Yasmin : Goedemiddag. Ik wil graag aangifte doen. Van een gestolen fiets.
Agent Visser : Dat kan. Is het uw fiets?
Yasmin : Nee, van mijn zoon. Hij is tien.
Agent Visser : Dan doet u de aangifte, mevrouw. Mag ik uw identiteitsbewijs zien?
Yasmin : Natuurlijk. Hier is mijn rijbewijs.
Agent Visser : Dank u. Mevrouw Aksoy. En jij bent...?
Emre : Emre. Emre Aksoy.
Agent Visser : Hallo, Emre. Vervelend, hè, van je fiets.
Emre : Ja. Heel vervelend.
Agent Visser : Vertel eens. Wanneer heb je je fiets voor het laatst gezien?
Emre : Gisteren, om vier uur. Toen ben ik thuisgekomen.
Agent Visser : En waar heb je hem neergezet?
Emre : Voor ons huis. Aan de gracht, bij het hek.
Agent Visser : Wat is uw adres, mevrouw?
Yasmin : (schrijft het op) Alstublieft. Het is het hoekhuis, boven het café.
Agent Visser : En wanneer heeft u gemerkt dat de fiets weg was?
Yasmin : Vanochtend om acht uur. Toen ging Emre naar school.
Agent Visser : Dus tussen gisteren vier uur en vanochtend acht uur.
Yasmin : Ja, precies.
Agent Visser : Kunt u de fiets beschrijven? Kleur, type, iets bijzonders?
Emre : Hij is blauw. Donkerblauw, met zwarte handvatten.
Yasmin : Een jongensfiets, zesentwintig inch. Met zeven versnellingen.
Agent Visser : Zijn er nog bijzonderheden? Stickers, een mandje?
Emre : Ja! Een sticker van Ajax. Achterop, op het spatbord.
Agent Visser : (glimlacht) Een Ajax-fan. Die fiets herken je dus meteen.
Emre : Bent u ook voor Ajax?
Agent Visser : Daar mag ik op mijn werk niks over zeggen. (knipoogt)
Yasmin : Hier is het framenummer. Ik heb een foto van de bon.
Agent Visser : Mooi. Dan zet ik het nummer in het systeem.
Yasmin : Wat gebeurt er dan?
Agent Visser : Dan staat de fiets geregistreerd als gestolen. Als een agent hem controleert, ziet hij dat meteen.
Emre : Dus u gaat hem zoeken?
Agent Visser : Eerlijk gezegd, Emre: we zoeken niet de hele stad af. Maar soms vinden we fietsen terug.
Yasmin : We hebben ook al bij het fietsdepot gekeken. Online.
Agent Visser : Heel goed. En? Stond hij erbij?
Yasmin : Nee, helaas niet.
Agent Visser : Was de fiets op slot?
Emre : (zachtjes) Ja. Met het ringslot. Maar niet vast aan het hek.
Agent Visser : Oké, dat schrijf ik ook op. Dat gebeurt heel vaak, hoor. Zo, dit is uw aangifte. Wilt u hem even doorlezen?
Yasmin : (leest) Ja, het klopt allemaal.
Agent Visser : Dan mag u hier tekenen. En dit is uw nummer, voor de verzekering.
Yasmin : De verzekering! Daar heb ik nog niet aan gedacht.
Agent Visser : Bel ze morgen even. Met dit nummer gaat het sneller.
Yasmin : Dank u wel voor uw hulp.
Agent Visser : Graag gedaan. Emre, volgende keer twee sloten. Afgesproken?
Emre : Afgesproken. Twee sloten. En altijd vast.
(Die avond. De werkplaats van Daan, één trap op. Overal staan fietsen en ligt gereedschap.)
Daan : Kom binnen! Hoe ging het bij de politie?
Emre : Goed. We hebben aangifte gedaan. De agent was aardig.
Daan : Mooi. En nu heb ik een verrassing voor je.
Emre : Een verrassing? Wat dan?
Daan : (trekt een oud laken weg) Tadaa! Een oude rode fiets.
Emre : Hij is... een beetje lelijk.
Daan : (lacht) Ja, lelijk is goed! Niemand steelt een lelijke fiets.
Yasmin : Daan, wat lief van je. Wat kost hij?
Daan : Niks. Hij heeft hier een jaar gestaan. Maar de remmen moeten nog gemaakt worden.
Emre : Mag ik helpen?
Daan : Natuurlijk. Zaterdag maken we hem samen. Dan leer je meteen sleutelen.
Emre : Cool! Mam, mag dat?
Yasmin : Ja, dat mag. Maar eerst kopen we een goede ketting.
Emre : En ik zet hem altijd vast. Aan een paal, een hek, een boom. Overal.
Yasmin : (lacht) Ja, ja. Dat geloof ik pas als ik het zie.
Emre : Mam! Ik heb echt mijn les geleerd.
Daan : Dat hoor ik graag. Nou, wie wil er een stroopwafel?
Emre : Ik! (pakt er twee)
Yasmin : Emre... één.
Emre : Eén is voor jou, mam. Ik heb vandaag nog een les geleerd: delen.

## 낭독 포인트
- g/ch: gisteren, gestolen, gebeurd, gemeente, geregistreerd, gracht, vlakbij의 g[ɣ/x]. 과거분사 접두사 ge-가 많은 화라 ge-를 목 안쪽에서 일정하게 낸다. "gracht"는 g와 ch가 한 단어에 다 들어 있다.
- ui: buiten, thuisgekomen, huis, gebruikt → ui[œy]. "naar buiten gegaan"을 한 호흡으로.
- ij/ei: rijbewijs, bijzonderheden, tijd, vlakbij(ij) / kleine, eigenlijk(ei). "rijbewijs"는 ij 두 개를 같은 소리로 읽는다.
- eu: gebeurd → eu[øː]. "Wanneer is het gebeurd?"에서 입술을 둥글게 한 '외'. ee(meteen, verzekering)와 구별한다.
- oe/uu: zoeken, goed, Hoekhuis(oe[u]) / duurt, uur(uu[yː]) — "Dat duurt twintig minuten"에서 duurt를 길게.
- sch: school, schrijf → s+ch[sx]. "Daar mag ik niks over zeggen"의 zeggen은 z+gg[ɣ].
- 축약·구어: m'n, Mam, Balen, Top, kerel, Tadaa, "Ga nou maar".
- 억양: 1장면 에므레는 숨이 차고 높게, 반복("Weg! … Eén week!")은 점점 크게. 경찰서 장면의 아헌트 피서르는 일정하고 차분한 공무 억양, 에므레에게는 한 톤 부드럽게. 마지막 "delen"은 의기양양하게 끝을 내린다.

## 학습 포인트 정리
- 완료시제 hebben: Ik heb overal gekeken. / Wanneer heb je hem neergezet? / Ik heb er een foto van gemaakt. / We hebben aangifte gedaan.
- 완료시제 zijn(장소 이동·상태 변화): Ik ben naar buiten gegaan. / Toen ben ik thuisgekomen. / Wanneer is het gebeurd? / Mijn fiets is gestolen.(수동 완료)
- 과거형(imperfectum)과 섞기: Hij stond hier. / Ik was moe. / Ik had haast. / Toen ging Emre naar school. — 장면 배경은 과거형, 일어난 사건은 완료형.
- 분리동사 과거분사: neerzetten → neergezet, thuiskomen → thuisgekomen, weghalen → weggehaald, afstellen → afgesteld.
- 신고 표현(시민): Ik wil graag aangifte doen. / Het is gestolen tussen … en … / Hier is het framenummer. / Het klopt allemaal.
- 신고 표현(경찰): Waarmee kan ik u helpen? / Mag ik uw identiteitsbewijs zien? / Wanneer heeft u … voor het laatst gezien? / Zijn er bijzonderheden? / Wilt u hem even doorlezen? / Dan mag u hier tekenen.
- 호칭: 경찰은 야스민에게 u, 열 살 에므레에게는 je. 에므레는 경찰에게 u("Bent u ook voor Ajax?").
- 위로·격려: Kom hier. / Kop op, kerel. / We vinden wel een oplossing. / Vervelend, hè.

## 속어 노트
- 이 화에는 아이가 거의 모든 장면에 있어 [속어] 태그가 붙는 거친 표현을 쓰지 않았다.
- Balen, man (가벼운 구어): '아 짜증 나겠다'. 아이 앞에서도 무난하다. man은 성별과 상관없이 친근하게 붙이는 말.
- stom / gemeen (일반 구어): '바보 같은' / '못된'. 아이들이 가장 흔히 쓰는 부정 형용사로, 거친 말이 아니다.
- canım (터키어): '내 사랑, 얘야'. 야스민이 아들을 달랠 때 무심코 튀어나오는 말 — 네덜란드어 문장 속 언어 전환의 예.

## 한글 해석
(목요일 아침 8시. 운하변 건물 앞. 에므레가 책가방을 메고 밖으로 나온다.)
에므레 : 엄마! 엄마, 와 봐! 내 자전거가 없어졌어!
야스민 : (계단을 내려오며) 뭐라고? 없어졌다고?
에므레 : 응, 없어! 여기 있었어. 울타리 옆에.
야스민 : 확실해? 잘 찾아봤어?
에므레 : 응! 다 찾아봤어. 여기, 저기, 다리 옆까지.
야스민 : 여기에 언제 세워 뒀는데?
에므레 : 어제. 학교 끝나고. 4시쯤인 것 같아.
야스민 : 그리고 자물쇠는 채웠어?
에므레 : 당연하지! 자물쇠 채웠어. 진짜야.
야스민 : 무슨 자물쇠로? 바퀴 자물쇠야, 체인이야?
에므레 : 어... 바퀴 자물쇠.
야스민 : 바퀴 자물쇠만? 에므레, 그럼 체인은 어디 있어?
에므레 : 위층 복도에 있어. 너무 무겁단 말이야, 엄마.
야스민 : (한숨) 아이고, 잔음(얘야). 단 아저씨가 그렇게 말했잖아.
에므레 : 알아. (울먹이며) 난 진짜 바보야.
야스민 : 아니야, 넌 바보 아니야. 도둑이 못된 거지.
에므레 : 산 지 겨우 일주일이야! 일주일!
야스민 : 알아, 우리 아들. 이리 와. (안아 준다)
에므레 : 나 우는 거 아니야. 그냥 눈에 뭐가 들어간 거야.
야스민 : 그래, 그래. 자, 학교 가야지. 오늘은 걸어가.
에므레 : 걸어서? 20분이나 걸리는데!
야스민 : 그럼 8시 20분에 도착하네. 시간 넉넉해.
(단이 커피 컵을 들고 막 't 훅여에서 나온다.)
단 : 좋은 아침, 악소이 가족! 무슨 일이에요? 둘 다 표정이 어두워요.
에므레 : 내 자전거 도둑맞았어요, 단 아저씨.
단 : 말도 안 돼! 그 파란 거? 내가 화요일에 손봐 준 거?
에므레 : 네. 없어졌어요.
단 : 아 속상하겠다. 언제 그랬대?
야스민 : 밤사이에 그런 것 같아요. 에므레가 어제 4시에 여기 세워 뒀거든요.
단 : 그리고 오늘 아침에 없어졌고.
에므레 : 네. 밖에 나왔는데... 아무것도 없었어요.
단 : 어떤 자물쇠 썼어?
에므레 : (바닥을 보며) 바퀴 자물쇠만요.
단 : 흠. 그리고 어디에 묶어 뒀어? 울타리나 기둥에?
에므레 : 아니요... 피곤했어요. 그리고 급했어요.
단 : 그렇구나. 그럼 그냥 들어서 가지고 가 버려. 2초면 돼.
에므레 : 진짜 못됐다!
단 : 그래, 정말 못됐지. 그런데 아직 작은 가능성이 하나 있어.
에므레 : 무슨 가능성이요?
단 : 어쩌면 시청에서 치워 갔을 수도 있어. 가끔 그런 일이 있거든.
야스민 : 시청이요? 왜요?
단 : 자전거가 엉뚱한 곳에 세워져 있으면요. 그러면 자전거 보관소로 가요.
야스민 : 그건 어떻게 확인해요?
단 : 온라인으로, 차대 번호로요. 자전거에 적혀 있는데, 영수증에도 있어요. 영수증 아직 있어요?
야스민 : 네, 사진 찍어 뒀어요. (휴대폰을 뒤진다) 여기요.
에므레 : 보관소에 없으면요?
단 : 그럼 신고해야 해. 경찰에.
야스민 : 오늘 바로 할 수 있어요?
단 : 네, 온라인으로 하거나 경찰서에 가면 돼요. 경찰서가 바로 근처, 레인바안스흐라흐트에 있어요.
야스민 : 그럼 오늘 오후에 가요, 학교 끝나고. 괜찮지, 에므레?
에므레 : 응. 근데 지금은 걸어가야 하네. (깊은 한숨)
단 : 야, 힘내, 친구. 방법은 찾으면 돼.
에므레 : 약속해요?
단 : 약속. 이제 어서 가, 안 그러면 늦어.
(그날 오후 3시 반. 레인바안스흐라흐트 경찰서. 야스민과 에므레가 접수대 앞에 서 있다.)
아헌트 피서르 : 안녕하세요. 무엇을 도와드릴까요?
야스민 : 안녕하세요. 신고를 하고 싶습니다. 자전거 도난이요.
아헌트 피서르 : 네, 됩니다. 본인 자전거인가요?
야스민 : 아니요, 아들 거예요. 열 살이에요.
아헌트 피서르 : 그럼 어머님이 신고하시면 됩니다. 신분증 좀 보여 주시겠어요?
야스민 : 물론이죠. 여기 운전면허증이요.
아헌트 피서르 : 감사합니다. 악소이 씨. 그리고 너는...?
에므레 : 에므레요. 에므레 악소이.
아헌트 피서르 : 안녕, 에므레. 자전거 일은 속상하지.
에므레 : 네. 엄청 속상해요.
아헌트 피서르 : 얘기해 볼래? 자전거를 마지막으로 본 게 언제야?
에므레 : 어제 4시요. 그때 집에 왔어요.
아헌트 피서르 : 그리고 어디에 세워 뒀어?
에므레 : 우리 집 앞이요. 운하 옆, 울타리 옆에요.
아헌트 피서르 : 주소가 어떻게 되세요?
야스민 : (적어 준다) 여기요. 카페 위층, 모퉁이 건물이에요.
아헌트 피서르 : 그리고 자전거가 없어진 걸 언제 아셨어요?
야스민 : 오늘 아침 8시요. 에므레가 학교 가려고 할 때요.
아헌트 피서르 : 그러니까 어제 4시부터 오늘 아침 8시 사이네요.
야스민 : 네, 맞아요.
아헌트 피서르 : 자전거 생김새를 말씀해 주시겠어요? 색깔, 종류, 특이한 점이요.
에므레 : 파란색이에요. 진한 파랑, 손잡이는 까만색이고요.
야스민 : 남자아이용 26인치 자전거예요. 7단 기어고요.
아헌트 피서르 : 다른 특징이 있나요? 스티커나 바구니 같은 거요.
에므레 : 네! 아약스 스티커요. 뒤쪽, 흙받이에요.
아헌트 피서르 : (미소 지으며) 아약스 팬이구나. 그럼 그 자전거는 바로 알아보겠네.
에므레 : 아저씨도 아약스 좋아해요?
아헌트 피서르 : 그건 근무 중에 말할 수가 없단다. (윙크한다)
야스민 : 여기 차대 번호요. 영수증 사진이 있어요.
아헌트 피서르 : 좋습니다. 그럼 번호를 시스템에 입력할게요.
야스민 : 그러면 어떻게 되나요?
아헌트 피서르 : 자전거가 도난품으로 등록됩니다. 경찰이 그 자전거를 검문하면 바로 알 수 있어요.
에므레 : 그럼 아저씨가 찾으러 가는 거예요?
아헌트 피서르 : 솔직히 말하면, 에므레, 도시 전체를 다 뒤지지는 않아. 그래도 가끔 자전거를 되찾기도 해.
야스민 : 자전거 보관소도 벌써 확인해 봤어요. 온라인으로요.
아헌트 피서르 : 아주 잘하셨어요. 그래서요? 거기 있었나요?
야스민 : 아니요, 안타깝게도 없었어요.
아헌트 피서르 : 자전거에 자물쇠는 채워져 있었나요?
에므레 : (작은 목소리로) 네. 바퀴 자물쇠로요. 근데 울타리에 묶지는 않았어요.
아헌트 피서르 : 그래, 그것도 적어 둘게. 그런 일 아주 흔해. 자, 이게 신고서입니다. 한번 읽어 보시겠어요?
야스민 : (읽는다) 네, 전부 맞아요.
아헌트 피서르 : 그럼 여기 서명해 주세요. 그리고 이건 보험용 접수 번호입니다.
야스민 : 보험! 그건 아직 생각도 못 했네요.
아헌트 피서르 : 내일 한번 전화해 보세요. 이 번호가 있으면 더 빨리 처리돼요.
야스민 : 도와주셔서 감사합니다.
아헌트 피서르 : 천만에요. 에므레, 다음엔 자물쇠 두 개. 약속?
에므레 : 약속해요. 자물쇠 두 개. 그리고 항상 묶어 두기.
(그날 저녁. 계단 하나 올라간 곳에 있는 단의 작업장. 곳곳에 자전거가 서 있고 공구가 널려 있다.)
단 : 들어와! 경찰서에서는 어떻게 됐어?
에므레 : 잘됐어요. 신고했어요. 경찰 아저씨가 친절했어요.
단 : 잘됐네. 그리고 지금 너한테 줄 깜짝 선물이 있어.
에므레 : 깜짝 선물이요? 뭔데요?
단 : (낡은 천을 걷어 낸다) 짜잔! 낡은 빨간 자전거.
에므레 : 이거... 좀 못생겼어요.
단 : (웃는다) 그래, 못생긴 게 좋은 거야! 아무도 못생긴 자전거는 안 훔쳐 가.
야스민 : 단, 정말 고마워요. 얼마예요?
단 : 공짜예요. 여기 1년이나 서 있었거든요. 근데 브레이크는 아직 고쳐야 해요.
에므레 : 저도 도와도 돼요?
단 : 당연하지. 토요일에 같이 고치자. 그러면 자전거 손보는 법도 바로 배우고.
에므레 : 신난다! 엄마, 해도 돼?
야스민 : 응, 해도 돼. 그런데 먼저 좋은 체인부터 사자.
에므레 : 그리고 나 항상 묶어 둘 거야. 기둥, 울타리, 나무. 어디든지.
야스민 : (웃는다) 그래, 그래. 그건 내 눈으로 봐야 믿겠다.
에므레 : 엄마! 나 진짜 교훈 얻었다니까.
단 : 그 말 들으니 좋다. 자, 스트로프와플 먹을 사람?
에므레 : 저요! (두 개를 집는다)
야스민 : 에므레... 하나만.
에므레 : 하나는 엄마 거야. 나 오늘 교훈 하나 더 얻었어: 나눠 먹기.
